| 字段 | 值 |

| 关联需求 | TR-0022（虚拟化基础功能） |

| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证虚拟网络地址获取、节点通信、隔离与访问控制符合预期，失败时有明确诊断。

## 前置条件（Setup）

1. 虚拟网络配置就绪（NAT/隔离网络）。

## 测试步骤（How to test）

1. 验证虚拟网络地址获取：客户机内 `ip addr`。
2. 规定节点间通信：`ping -c 4 <对端>`。
3. 验证隔离与访问控制（如跨网络不可达、防火墙限制）。
4. 触发操作失败场景（如错误的设备/网络配置）。

## 预期结果（Expected Results）

1. 步骤 1：客户机获得预期网络地址。
2. 步骤 2：规定节点间通信正常。
3. 步骤 3：隔离与访问控制符合预期。
4. 步骤 4：失败时提供明确诊断，无磁盘损坏。
