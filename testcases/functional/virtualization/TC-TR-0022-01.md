# TC-TR-0022-01 ｜ 虚拟机生命周期

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0022（虚拟化基础功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 虚拟化 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 libvirt/QEMU 虚拟机定义、创建、启动、状态查询、关机及删除全生命周期正常，无资源残留。

## 前置条件（Setup）

1. 客户机镜像与虚拟化配置就绪（libvirtd 运行）。

## 测试步骤（How to test）

1. 定义虚拟机：`virsh define <xml>`。
2. 启动虚拟机：`virsh start <域>`。
3. 查询状态：`virsh list --all`、`virsh dominfo <域>`。
4. 正常关机：`virsh shutdown <域>`。
5. 删除虚拟机：`virsh undefine <域>`。

## 预期结果（Expected Results）

1. 步骤 1/2：定义与启动成功。
2. 步骤 3：状态显示 `running`，关机后为 `shut off`。
3. 步骤 4：正常关机。
4. 步骤 5：删除成功，无宿主机崩溃与非预期资源残留。
