# TC-TR-0022-03 ｜ 虚拟磁盘读写与重启一致

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0022（虚拟化基础功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 虚拟化 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证虚拟磁盘正常识别与读写，数据在客户机重启后保持一致。

## 前置条件（Setup）

1. 虚拟磁盘已挂载。

## 测试步骤（How to test）

1. 向虚拟磁盘写入数据并记录校验和。
2. 重启客户机：`virsh reboot <域>` 或客户机内 `reboot`。
3. 校验数据：重新计算校验和并对比。

## 预期结果（Expected Results）

1. 步骤 1：写入成功。
2. 步骤 3：数据在重启后保持一致（校验和相同）。
