# TC-TR-0022-02 ｜ 客户机设备识别

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0022（虚拟化基础功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 虚拟化 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证客户机进入操作系统后识别配置的虚拟 CPU、内存及规定设备。

## 前置条件

1. 已配置虚拟 CPU/内存及规定设备（网卡、磁盘等）。

## 测试步骤

1. 配置虚拟 CPU/内存及规定设备（在 XML / `virt-install` 中指定）。
2. 客户机进入操作系统。
3. 检查识别结果：`lscpu`、`free -h`、`lspci` / `lsblk`。

## 预期结果

1. 步骤 3：客户机识别的 CPU 数量、内存容量与配置一致，规定设备被识别。
