## 描述

验证 gcc 编译链接含标准头文件、标准库调用及简单运算的 C 程序成功并可正常运行。

## 前置条件

安装 gcc 及规定的开发依赖

## 测试步骤

1. 执行 gcc --version
2. 编写含标准头文件、标准库调用、简单运算的 C 程序
3. 使用 gcc 编译链接
4. 运行生成的可执行文件

## 预期结果

1. 版本信息正常显示
2. 编译链接成功且退出码为 0
3. 程序运行输出符合预期且退出码为 0
