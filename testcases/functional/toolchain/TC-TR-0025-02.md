## 描述

验证含明确语法错误的源文件编译返回非零退出码与错误诊断且编译器不崩溃。

## 前置条件

1. 已安装 gcc、binutils 及对应开发依赖（如 glibc-devel）。
2. 具备可写工作目录（如 `/tmp`）。

## 测试步骤

1. 编写含明确语法错误的 C 源文件：
   ```bash
   CASE_TMP=/tmp/tc-gcc && mkdir -p $CASE_TMP
   cat > $CASE_TMP/gcc-syntax-bad.c <<'EOF'
   int main(void) {
       int x = ;
       return 0;
   }
   EOF
   ```
2. 编译错误源文件：
   ```bash
   gcc -o $CASE_TMP/gcc-syntax-bad $CASE_TMP/gcc-syntax-bad.c
   ```
3. 确认编译器未崩溃（再次执行 gcc 可正常运行）：
   ```bash
   gcc --version
   ```
4. 清理测试目录：
   ```bash
   rm -rf $CASE_TMP
   ```

## 预期结果

1. 步骤 2：编译返回非零退出码，输出以 `error:` 开头的错误诊断信息（指明错误位置与原因）。
2. 步骤 3：`gcc --version` 仍能正常输出，退出码为 0，编译器无崩溃。
3. 步骤 4：测试产物清理完毕。
