## 描述

验证 gcc 编译链接含标准头文件、标准库调用及简单运算的 C 程序成功并可正常运行。

## 前置条件

1. 已安装 gcc、binutils 及对应开发依赖（如 glibc-devel）。
2. 具备可写工作目录（如 `/tmp`）。

## 测试步骤

1. 查看 gcc 版本信息：
   ```bash
   gcc --version
   ```
2. 编写包含标准头文件、标准库调用及简单运算的 C 程序：
   ```bash
   CASE_TMP=/tmp/tc-gcc && mkdir -p $CASE_TMP
   cat > $CASE_TMP/gcc-hello.c <<'EOF'
   #include <stdio.h>
   int main(void) {
       int a = 1, b = 2;
       printf("%d\n", a + b);
       return 0;
   }
   EOF
   ```
3. 编译并链接：
   ```bash
   gcc -o $CASE_TMP/gcc-hello $CASE_TMP/gcc-hello.c
   ```
4. 运行生成的可执行文件：
   ```bash
   $CASE_TMP/gcc-hello
   ```
5. 清理测试目录：
   ```bash
   rm -rf $CASE_TMP
   ```

## 预期结果

1. 步骤 1：`gcc --version` 正常输出版本信息，退出码为 0。
2. 步骤 3：编译链接成功，退出码为 0，生成可执行文件 `/tmp/gcc-hello`。
3. 步骤 4：程序输出 `3`，程序退出码为 0。
4. 步骤 5：测试产物清理完毕，无残留。
