| 自动化覆盖 | 否 |

## 描述

验证容器网络地址分配、路由设置、规定范围通信及隔离访问控制符合配置。

## 前置条件

1. 容器网络插件可用。

## 测试步骤

1. 验证地址分配：`podman inspect <名>` 或容器内 `ip addr`。
2. 验证路由设置：容器内 `ip route`。
3. 规定范围通信：容器间/与宿主 `ping`、`curl`。
4. 验证隔离与访问控制（如不同网络/网络策略）。

## 预期结果

1. 步骤 1：容器获得预期网络地址。
2. 步骤 2：路由设置符合配置。
3. 步骤 3：规定范围通信正常。
4. 步骤 4：隔离与访问控制符合预期。
