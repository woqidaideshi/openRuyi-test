# TC-TR-0023-03 ｜ 容器网络

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0023（容器运行时功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 云原生 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证容器网络的地址分配、路由设置、同网络与跨网络通信及网络隔离符合配置。

## 前置条件

1. 容器网络插件可用（podman 自带 CNI/netavark）。

## 测试步骤

1. 执行 `podman network create net1` 创建自定义网络，执行 `podman network ls` 查看。
2. 在 net1 上启动两个容器：
   - 启动 c1-net1 `podman run -d --name c1-net1 --network net1 <镜像> sleep 300`；
   - 启动 c2-net1 `podman run -d --name c2-net1 --network net1 <镜像> sleep 300`。
3. 查看 c1-net1 的地址分配与路由：
   - 查看 c1-net1 的地址分配 `podman exec c1-net1 ip -br addr`；
   - 查看 c1-net1 的路由 `podman exec c1-net1 ip route`。
4. 测 c1-net1 到 c2-net1 的连通性（两者在同一网络 net1）：
   - 取 c2-net1 的 IP `podman inspect -f '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' c2-net1`；
   - 从 c1-net1 ping c2-net1 的容器名 `podman exec c1-net1 ping -c 3 c2-net1`；
   - 从 c1-net1 ping c2-net1 的 IP `podman exec c1-net1 ping -c 3 <c2-net1 的 IP>`。
5. 测 c1-net1 到 c3-net2 的连通性（两者在不同网络）：
   - 创建第二个网络 `podman network create net2`；
   - 启动 c3-net2 `podman run -d --name c3-net2 --network net2 <镜像> sleep 300`；
   - 取 c3-net2 的 IP `podman inspect -f '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' c3-net2`；
   - 从 c1-net1 ping c3-net2 的容器名 `podman exec c1-net1 ping -c 3 c3-net2`；
   - 从 c1-net1 ping c3-net2 的 IP `podman exec c1-net1 ping -c 3 <c3-net2 的 IP>`。
6. 按 IP 双向测试两个隔离网络之间的连通性：
   - 创建隔离网络 net4 `podman network create --opt isolate=true net4`；
   - 启动 c4-net4 `podman run -d --name c4-net4 --network net4 <镜像> sleep 300`；
   - 创建第二个隔离网络 net5 `podman network create --opt isolate=true net5`；
   - 启动 c5-net5 `podman run -d --name c5-net5 --network net5 <镜像> sleep 300`；
   - 取 c4-net4 的 IP `podman inspect -f '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' c4-net4`；
   - 取 c5-net5 的 IP `podman inspect -f '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' c5-net5`；
   - 从 c4-net4 ping c5-net5 的 IP `podman exec c4-net4 ping -c 3 <c5-net5 的 IP>`；
   - 从 c5-net5 ping c4-net4 的 IP `podman exec c5-net5 ping -c 3 <c4-net4 的 IP>`。
7. 按 IP 双向测试隔离网络与普通网络之间的连通性：
   - 取 c1-net1 的 IP `podman inspect -f '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' c1-net1`；
   - 从 c4-net4 ping c1-net1 的 IP `podman exec c4-net4 ping -c 3 <c1-net1 的 IP>`；
   - 从 c1-net1 ping c4-net4 的 IP `podman exec c1-net1 ping -c 3 <c4-net4 的 IP>`。
8. 清理：删除容器 c1-net1、c2-net1、c3-net2、c4-net4、c5-net5，删除网络 net1、net2、net4、net5。

## 预期结果

1. 步骤 1：net1 创建完成，`podman network ls` 可见。
2. 步骤 2：c1-net1 与 c2-net1 均处于 `running`。
3. 步骤 3：c1-net1 获得与 net1 同网段的私有地址（如 `10.89.0.2/24`），默认路由指向该网段网关（如 `10.89.0.1`）。
4. 步骤 4：c1-net1 到 c2-net1 按容器名与按 IP 两种方式均 ping 通，丢包率 0%。
5. 步骤 5：c1-net1 ping c3-net2 的容器名不可解析（提示 `Name or service not known`），按 IP 可 ping 通，丢包率 0%。
6. 步骤 6：c4-net4 与 c5-net5 之间按 IP 双向均不通（丢包率 100%），两个启用 `isolate=true` 的网络相互隔离。
7. 步骤 7：c4-net4 与 c1-net1 之间按 IP 双向均 ping 通，丢包率 0%。
8. 步骤 8：容器与自定义网络均已删除，无残留（内置 `podman` 网络保留）。
