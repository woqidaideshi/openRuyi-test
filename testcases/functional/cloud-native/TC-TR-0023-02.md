# TC-TR-0023-02 ｜ 容器生命周期

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0023（容器运行时功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 云原生 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证容器创建、启动、状态查询、停止、删除生命周期正常，程序结果与退出状态正确。

## 前置条件

1. 镜像已拉取（如 alpine）。

## 测试步骤

1. 执行 `podman create --name c1 <镜像> echo hello` 创建容器，执行 `podman ps -a` 与 `podman inspect -f '{{.State.Status}}' c1` 查看状态。
2. 执行 `podman start c1` 启动，再执行 `podman inspect -f '{{.State.Status}}' c1` 查看状态。
3. 执行 `podman logs c1` 查看容器内程序输出，执行 `podman inspect -f '{{.State.ExitCode}}' c1` 查看退出码。
4. 执行 `podman run --rm <镜像> sh -c 'exit 42'` 运行容器，查看宿主侧返回码。
5. 执行 `podman run -d --name c2 <镜像> sleep 300` 启动长驻容器，执行 `podman stop c2` 停止，再执行 `podman inspect -f '{{.State.Status}}' c2` 与 `podman inspect -f '{{.State.ExitCode}}' c2` 查看状态与退出码。
6. 执行 `podman rm c1 c2` 删除容器，执行 `podman ps -a` 确认剩余容器。

## 预期结果

1. 步骤 1：创建完成，`podman ps -a` 可见该容器，状态为 `created`。
2. 步骤 2：启动完成，短命令执行完毕后状态为 `exited`。
3. 步骤 3：输出 `hello`，退出码为 0。
4. 步骤 4：宿主侧返回码为 42，退出码透传正确。
5. 步骤 5：停止完成，状态为 `exited`；在约定的 10 秒宽限期后被 `SIGKILL`，退出码为 137。
6. 步骤 6：两个容器均已删除，`podman ps -a` 中不再出现。
