# TC-TR-0023-02 ｜ 容器生命周期

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0023（容器运行时功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 云原生 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证容器创建、启动、状态查询、停止、删除生命周期正常，程序结果与退出状态正确。

## 前置条件

1. 镜像已拉取（如 alpine）。

## 测试步骤

1. 创建容器：
   ```bash
   podman create --name c1 <镜像> echo hello
   podman ps -a
   ```
2. 启动容器并查询状态：
   ```bash
   podman start c1
   podman ps
   podman inspect -f '{{.State.Status}}' c1
   ```
3. 查看容器内程序输出与退出状态：
   ```bash
   podman logs c1
   podman inspect -f '{{.State.ExitCode}}' c1
   ```
4. 验证退出码透传：
   ```bash
   podman run --rm <镜像> sh -c 'exit 42'
   echo $?
   ```
5. 删除容器：
   ```bash
   podman rm c1
   podman ps -a
   ```

## 预期结果

1. 步骤 1：容器创建成功，状态为 `Created`。
2. 步骤 2：启动成功，状态为 `running` → `exited`。
3. 步骤 3：容器内程序输出 `hello`，退出状态为 0。
4. 步骤 4：退出码 42 正确透传到宿主侧。
5. 步骤 5：容器删除成功，无残留。

## 实测记录（2026-11-10，riscv64 物理机，podman 5.8.2）

| 步骤 | 实测结果 |
|---|---|
| `podman create --name c1 … echo hello` | 返回容器 ID，`State.Status` = `created` |
| `podman start c1` | 正常，状态变为 `exited`（短命进程执行完毕） |
| `podman logs c1` | 输出 `hello` |
| `State.ExitCode` | `0` |
| `podman run --rm … 'exit 42'; echo $?` | 宿主侧得到 **`42`**，退出码透传正确 |
| `podman rm c1` | 成功，`podman ps -a` 无残留（`residual_containers=0`） |

> 说明：`podman start` 后状态很快从 `running` 变为 `exited` 属正常（命令仅 `echo hello` 后立即退出）。若要稳定观察 `running` 状态，请用长命进程（如 `sleep 300`）。
