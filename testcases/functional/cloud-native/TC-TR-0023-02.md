# TC-TR-0023-02 ｜ 容器生命周期

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0023（容器运行时功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 云原生 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证容器创建、启动、状态查询、停止、删除生命周期正常，程序结果与退出状态正确。

## 前置条件

1. 镜像已拉取。

## 测试步骤

1. 创建容器：`podman create --name <名> <镜像>`。
2. 启动容器：`podman start <名>`。
3. 查询状态：`podman ps -a`。
4. 容器内程序运行：`podman exec <名> <命令>`。
5. 停止容器：`podman stop <名>`。
6. 删除容器：`podman rm <名>`。

## 预期结果

1. 步骤 1~3：创建/启动成功，状态正确（`Up`/`Exited`）。
2. 步骤 4：容器内程序运行结果与退出状态正确。
3. 步骤 5/6：停止与删除成功。
