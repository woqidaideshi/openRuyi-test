# TC-TR-0023-01 ｜ 镜像拉取校验解包

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0023（容器运行时功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 云原生 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证容器镜像从规定仓库拉取、内容完整性校验与解包正常。

## 前置条件

1. 规定镜像仓库可达。

## 测试步骤

1. 拉取与目标架构匹配的镜像：`podman pull <仓库>/<镜像>:<标签>`。
2. 内容完整性校验：`podman images` 确认镜像存在。
3. 解包（由运行时自动完成），确认可基于镜像创建容器。

## 预期结果

1. 步骤 1：拉取成功，退出码为 0。
2. 步骤 2：镜像出现在本地镜像列表，内容完整。
3. 步骤 3：解包正常，可基于镜像创建容器。
