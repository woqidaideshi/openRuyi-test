# TC-TR-0023-01 ｜ 镜像拉取校验解包

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0023（容器运行时功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 云原生 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证容器镜像从规定仓库拉取、内容完整性校验与解包正常。

## 前置条件

1. 已安装 podman，具备可用用户或 root 权限。
2. 规定镜像仓库可达，且仓库中存在 riscv64 架构镜像。

## 测试步骤

1. 查看 `podman version`、`uname -m`，并执行 `podman info --format '{{.Host.OCIRuntime.Name}}'` 查看默认 OCI 运行时。
2. 从规定仓库拉取与 riscv64 匹配的镜像（`podman pull <仓库>/<镜像>:<标签>`），并执行 `podman images` 查看。
3. 执行 `podman inspect <镜像> --format '{{.Digest}}'` 获取镜像摘要，与仓库公布的 digest 比对。
4. 执行 `podman run --rm <镜像> uname -m` 在容器内查看架构。
5. 执行 `podman rmi <镜像>` 删除该镜像，并执行 `podman images` 查看。

## 预期结果

1. 步骤 1：版本信息正常，架构为 riscv64，默认 OCI 运行时为产品默认运行时（如 `crun`）。
2. 步骤 2：拉取完成，退出码为 0，`podman images` 可见该镜像。
3. 步骤 3：本地 digest 与仓库公布值一致，内容完整性校验通过。
4. 步骤 4：容器内 `uname -m` 输出 `riscv64`。
5. 步骤 5：镜像已删除，`podman images` 中不再出现该镜像。
