# TC-TR-0010-03 ｜ 防火墙规则生效

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0010（网络基础功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 网络 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证防火墙允许与拒绝规则正确生效，无非预期放行。

## 前置条件（Setup）

1. firewalld / nftables / iptables 可用。

## 测试步骤（How to test）

1. 配置允许规则（如放行 22 端口），从对端验证放行。
2. 配置拒绝规则（如拒绝某端口），从对端验证拒绝。
3. 核对默认策略（`firewall-cmd --list-all` 或 `nft list ruleset`），确认无非预期放行。

## 预期结果（Expected Results）

1. 步骤 1：允许规则正确放行，服务可访问。
2. 步骤 2：拒绝规则正确生效，连接被拒。
3. 步骤 3：无非预期放行。
