# TC-TR-0011-01 ｜ wifi 连接成功且重登免密

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0011（使用 wifi 联网） |
| 测试类型 | 功能测试 |
| 功能模块 | 网络 |
| 优先级 | P2 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证 wifi 使用正确密码连接成功、可访问 openruyi.cn 网页，且重新登录后免密。

## 前置条件

1. 配备可用无线网卡并处于无线网络覆盖范围内。
2. 已安装 wpa_supplicant、NetworkManager，NetworkManager 运行正常。
3. 已知目标 SSID 与正确密码。
4. **必须有真实无线网卡**：`nmcli radio wifi` 即使无任何无线设备也会返回 `enabled`，不能用它判断是否有无线能力，应使用 `iw dev` 确认：
   ```bash
   iw dev
   ```
   若 `iw dev` 无输出、`nmcli -t -f DEVICE,TYPE device status` 只有 `ethernet`/`loopback`，则本用例**不可在当前设备执行**（实测该 riscv64 物理机无无线网卡，且内核未提供 `mac80211_hwsim` 模拟模块，无法用模拟方式代替）。

## 测试步骤

1. 确认工具与无线开关：
   ```bash
   rpm -q wpa_supplicant NetworkManager
   systemctl is-active NetworkManager
   iw dev
   ```
   > 提示：openRuyi **默认不安装 `wpa_supplicant`**（实测 `rpm -q wpa_supplicant` → `package wpa_supplicant is not installed`；仓库提供 `wpa_supplicant-2.11-3.37.or`）。执行前需 `sudo dnf install -y wpa_supplicant`。
2. 扫描目标 SSID：
   ```bash
   nmcli device wifi list | grep <SSID>
   ```
3. 使用正确密码连接：
   ```bash
   sudo nmcli device wifi connect <SSID> password <密码>
   nmcli -t -f GENERAL.STATE device show <无线接口>
   ```
4. 访问网页验证：
   ```bash
   curl -I https://openruyi.cn
   ```
5. 重启后确认免密自动连接：
   ```bash
   sudo systemctl reboot
   nmcli -t -f ACTIVE,SSID connection show
   ```

## 预期结果

1. 步骤 1：工具已安装，NetworkManager active，`iw dev` 能列出无线接口（如 `phy#0 / Interface wlan0`）。
2. 步骤 2：扫描到目标 SSID。
3. 步骤 3：连接进入 activated 状态，无需反复认证。
4. 步骤 4：`curl -I` 返回 HTTP 200，网页可访问。
5. 步骤 5：重启后自动连接同一 SSID，无需再次输入密码。

> 环境提示：本用例需在配备无线网卡的设备（或虚拟机挂载 USB 无线网卡 / 内核支持 `mac80211_hwsim` 时）执行，纯有线服务器不具备执行条件。
