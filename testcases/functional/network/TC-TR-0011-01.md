# TC-TR-0011-01 ｜ wifi 连接成功且重登免密

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0011（使用 wifi 联网） |
| 测试类型 | 功能测试 |
| 功能模块 | 网络 |
| 优先级 | P2 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证 wifi 使用正确密码连接成功、可访问 openruyi.cn 网页，且重新登录后免密。

## 前置条件

1. 移除网线；存在可用 wifi 网络并已知正确密码。

## 测试步骤

1. 使用 `nmtui` 选择对应 wifi 并输入正确密码连接。
2. 确认连接状态：`nmcli con show --active`。
3. 访问网页：`curl -I https://openruyi.cn`。
4. 重新登录后再次连接该 wifi，观察是否需要重复输入密码。

## 预期结果

1. 步骤 1/2：连接成功，接口获得 IP。
2. 步骤 3：`curl` 返回 HTTP 200，网页可访问。
3. 步骤 4：重新登录后免密自动连接，无需重复输入密码。
