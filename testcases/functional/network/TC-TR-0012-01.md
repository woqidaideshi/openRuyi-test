# TC-TR-0012-01 ｜ ssh 有效凭据建立会话

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0012（正常通过 ssh 连接 openruyi 机器） |
| 测试类型 | 功能测试 |
| 功能模块 | 网络 |
| 优先级 | P2 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 ssh 使用有效凭据进入交互式 Shell，会话内命令与文件操作正常，退出后重连成功。

## 前置条件

网络连通；ssh 服务启用；端口放行；openruyi 用户与认证方式配置正确

## 测试步骤

1. 执行 ssh -p <端口> openruyi@<地址>
2. whoami 确认用户
3. 执行基本命令
4. 授权目录内文件创建/读取/删除
5. exit 退出
6. 再次连接

## 预期结果

1. 进入交互式 Shell
2. whoami 输出 openruyi
3. 基本命令可执行
4. 文件操作成功
5. 退出后重连成功
