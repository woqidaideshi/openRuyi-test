# TC-TR-0012-01 ｜ ssh 有效凭据建立会话

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0012（正常通过 ssh 连接 openruyi 机器） |
| 测试类型 | 功能测试 |
| 功能模块 | 网络 |
| 优先级 | P2 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 ssh 使用有效凭据进入交互式 Shell，会话内命令与文件操作正常，退出后重连成功。

## 前置条件

1. 网络连通；sshd 已启用；端口放行；openruyi 用户与认证方式配置正确。
2. 已安装 sshpass（用于自动化）。
3. 若 `openruyi` 仅配置了密钥登录（未设密码），可临时创建一个测试用户完成密码认证验证，验证后删除：
   ```bash
   sudo useradd -m -s /bin/bash tcuser
   printf 'TcPass123\nTcPass123\n' | sudo passwd tcuser
   # ...执行下方步骤（将 openruyi 换为 tcuser、密码换为 TcPass123）...
   sudo userdel -r tcuser
   ```

> 自动化注意（实测踩坑）：在脚本/heredoc 中调用内层 `ssh` 时必须加 `-n` 或 `</dev/null`，否则内层 ssh 会吞掉外层脚本的标准输入（表现为脚本执行到一半无输出即中止）。下文命令已统一加 `</dev/null`。

## 测试步骤

1. 连接并确认用户与目录：
   ```bash
   sshpass -p '<正确密码>' ssh -n -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null -o PreferredAuthentications=password -o PubkeyAuthentication=no openruyi@localhost 'whoami; pwd' </dev/null
   echo $?
   ```
2. 授权目录内文件创建/读取/删除：
   ```bash
   sshpass -p '<正确密码>' ssh -n -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null -o PreferredAuthentications=password -o PubkeyAuthentication=no openruyi@localhost 'echo hi > /home/openruyi/tc-file; cat /home/openruyi/tc-file; rm /home/openruyi/tc-file; echo done' </dev/null
   ```
3. 退出后再次连接：
   ```bash
   sshpass -p '<正确密码>' ssh -n -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null -o PreferredAuthentications=password -o PubkeyAuthentication=no openruyi@localhost 'echo reconnect-ok' </dev/null
   ```
4. 反向验证（错误密码必须被拒）：
   ```bash
   sshpass -p '<错误密码>' ssh -n -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null -o PreferredAuthentications=password -o PubkeyAuthentication=no -o NumberOfPasswordPrompts=1 openruyi@localhost 'echo should-not-happen' </dev/null
   echo $?
   ```

## 预期结果

1. 步骤 1：进入交互式 Shell，`whoami` 输出 `openruyi`，`pwd` 输出 `/home/openruyi`，退出码为 0。
2. 步骤 2：文件创建、读取、删除成功，输出 `hi` 与 `done`，退出码为 0。
3. 步骤 3：退出后重连成功，输出 `reconnect-ok`，退出码为 0。
4. 步骤 4：错误密码连接失败，退出码非 0（实测 `255`），提示 `Permission denied (publickey,password)`，且**不输出** `should-not-happen`（未建立会话）。
