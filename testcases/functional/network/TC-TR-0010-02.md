# TC-TR-0010-02 ｜ 连通性与故障恢复

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0010（网络基础功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 网络 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证规定节点间网络连通，故障解除后能够按配置恢复。

## 前置条件（Setup）

1. 规定节点可达，并具备制造/解除网络故障的手段。

## 测试步骤（How to test）

1. 验证连通：`ping -c 4 <目标节点>`。
2. 制造网络故障（如断开网络、`ip link set <接口> down` 或拔线）。
3. 故障解除后验证恢复：`ping -c 4 <目标节点>`，并核对 `ip addr` / `ip route`。

## 预期结果（Expected Results）

1. 步骤 1：ping 全部可达（0% 丢包）。
2. 步骤 2：故障生效，ping 不可达。
3. 步骤 3：故障解除后按配置恢复，ping 可达且网络配置正确。
