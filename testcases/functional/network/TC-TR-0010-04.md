# TC-TR-0010-04 ｜ 防火墙规则（firewalld）

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0010（网络基础功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 网络 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

通过 `firewall-cmd` 验证防火墙允许与拒绝规则正确生效：未放行端口默认不可达，放行后对端可访问，未放行的对照端口不被意外放通，`--permanent` 规则在重启后仍生效，移除放行规则后立即重新阻断。

## 前置条件

1. 已安装 `firewalld`。
2. 具备 root 权限（sudo）。
3. **需要一台能访问被测机的外部对端主机**，回环地址不能代替。
4. 默认 zone 的 `services` 中已包含管理连接所使用的服务（`public` zone 默认包含 `ssh`）。
5. `firewalld` 与 `nftables` 包存在替代关系：安装 `firewalld` 会替换/升级 `nftables` 包，`nft` 命令仍可正常使用。
6. **测试端口由步骤 2 自动选取**：在被测机上从未被监听、未被 `firewall-cmd` 放通（含 rich rule）的端口中挑两个（默认从 `18800` 起），分别作放行端口与对照端口。若选取失败（区间内无可用端口），用例判为不可执行。
7. **步骤 6 需重启整机**，须在可占用整机的测试窗口执行。

## 测试步骤

1. 确认已安装并启动 firewalld，记录基线：
   ```bash
   CASE_TMP=/var/tmp/tc-fw-cmd && rm -rf $CASE_TMP && mkdir -p $CASE_TMP
   printf 'CASE_TMP=%s\n' "$CASE_TMP" > $CASE_TMP/env.sh
   rpm -q firewalld || sudo dnf install -y firewalld
   sudo systemctl enable --now firewalld
   sudo firewall-cmd --state
   sudo firewall-cmd --get-default-zone
   sudo firewall-cmd --list-all
   sudo firewall-cmd --list-ports > $CASE_TMP/before.ports
   sudo firewall-cmd --permanent --list-ports > $CASE_TMP/before.ports-perm
   cat /proc/sys/kernel/random/boot_id > $CASE_TMP/before.bootid
   ```
2. 自动选取两个测试端口并起监听（结果写入 `env.sh`，供重启后复用）：
   ```bash
   CASE_TMP=/var/tmp/tc-fw-cmd && . $CASE_TMP/env.sh
   pick_port() {
     for p in $(seq "${PORT_BASE:-18800}" 18850); do
       [ "$p" = "${1:-}" ] && continue
       ss -ltnH "sport = :$p" 2>/dev/null | grep -q . && continue
       sudo firewall-cmd --query-port="$p/tcp" >/dev/null 2>&1 && continue
       sudo firewall-cmd --list-rich-rules 2>/dev/null | grep -q "dport=$p" && continue
       echo "$p"; return 0
     done
     return 1
   }
   PORT_ALLOW=$(pick_port)
   PORT_CTRL=$(pick_port "$PORT_ALLOW")
   echo "PORT_ALLOW=$PORT_ALLOW PORT_CTRL=$PORT_CTRL"
   [ -n "$PORT_ALLOW" ] && [ -n "$PORT_CTRL" ] || echo "pick-failed"
   printf 'PORT_ALLOW=%s\nPORT_CTRL=%s\n' "$PORT_ALLOW" "$PORT_CTRL" >> $CASE_TMP/env.sh
   sudo setsid python3 -m http.server "$PORT_ALLOW" >/dev/null 2>&1 < /dev/null &
   echo $! > $CASE_TMP/pallow.pid
   sudo setsid python3 -m http.server "$PORT_CTRL" >/dev/null 2>&1 < /dev/null &
   echo $! > $CASE_TMP/pctrl.pid
   sleep 2
   ss -ltn | grep -E ":($PORT_ALLOW|$PORT_CTRL)\b"
   ```
3. 从**对端主机**确认两个端口默认均不可达：
   ```bash
   # 在对端执行，<目标IP> 为被测机地址，端口取步骤 2 输出的 PORT_ALLOW / PORT_CTRL
   curl -s -o /dev/null -w 'allow=%{http_code}\n' --max-time 5 http://<目标IP>:<PORT_ALLOW>/
   curl -s -o /dev/null -w 'ctrl=%{http_code}\n'  --max-time 5 http://<目标IP>:<PORT_CTRL>/
   ```
4. 放行 `$PORT_ALLOW/tcp`（运行时 + 永久）并 reload：
   ```bash
   CASE_TMP=/var/tmp/tc-fw-cmd && . $CASE_TMP/env.sh
   sudo firewall-cmd --add-port="$PORT_ALLOW/tcp"
   sudo firewall-cmd --permanent --add-port="$PORT_ALLOW/tcp"
   sudo firewall-cmd --reload
   sudo firewall-cmd --list-ports
   sudo firewall-cmd --permanent --list-ports
   sudo firewall-cmd --query-port="$PORT_ALLOW/tcp"; echo "query-allow:$?"
   ```
5. 从**对端**验证放行生效、对照端口仍不可达：
   ```bash
   # 在对端执行
   curl -s -o /dev/null -w 'allow=%{http_code}\n' --max-time 5 http://<目标IP>:<PORT_ALLOW>/
   curl -s -o /dev/null -w 'ctrl=%{http_code}\n'  --max-time 5 http://<目标IP>:<PORT_CTRL>/
   ```
6. 重启系统，验证 `--permanent` 规则持久化：

   执行重启：
   ```bash
   sudo reboot
   ```

   重启后重新接入，确认已切换到新的启动：
   ```bash
   CASE_TMP=/var/tmp/tc-fw-cmd && . $CASE_TMP/env.sh
   cat /proc/sys/kernel/random/boot_id > $CASE_TMP/after.bootid
   echo "before=$(cat $CASE_TMP/before.bootid) after=$(cat $CASE_TMP/after.bootid)"
   [ "$(cat $CASE_TMP/after.bootid)" != "$(cat $CASE_TMP/before.bootid)" ]
   echo "bootid-changed:$?"
   sudo systemctl is-active firewalld
   sudo firewall-cmd --list-ports
   sudo firewall-cmd --permanent --list-ports
   sudo firewall-cmd --query-port="$PORT_ALLOW/tcp"; echo "query-allow-after-reboot:$?"
   ```
7. 重启后重新起监听，并从**对端**确认放行仍然生效：
   ```bash
   CASE_TMP=/var/tmp/tc-fw-cmd && . $CASE_TMP/env.sh
   sudo setsid python3 -m http.server "$PORT_ALLOW" >/dev/null 2>&1 < /dev/null &
   echo $! > $CASE_TMP/pallow.pid
   sudo setsid python3 -m http.server "$PORT_CTRL" >/dev/null 2>&1 < /dev/null &
   echo $! > $CASE_TMP/pctrl.pid
   sleep 2
   ss -ltn | grep -E ":($PORT_ALLOW|$PORT_CTRL)\b"
   # 在对端执行
   curl -s -o /dev/null -w 'allow=%{http_code}\n' --max-time 5 http://<目标IP>:<PORT_ALLOW>/
   curl -s -o /dev/null -w 'ctrl=%{http_code}\n'  --max-time 5 http://<目标IP>:<PORT_CTRL>/
   ```
8. 移除放行规则并 reload，从**对端**验证重新阻断：
   ```bash
   CASE_TMP=/var/tmp/tc-fw-cmd && . $CASE_TMP/env.sh
   sudo firewall-cmd --permanent --remove-port="$PORT_ALLOW/tcp"
   sudo firewall-cmd --reload
   sudo firewall-cmd --list-ports
   sudo firewall-cmd --permanent --list-ports
   sudo firewall-cmd --query-port="$PORT_ALLOW/tcp"; echo "query-allow-after-remove:$?"
   # 在对端执行
   curl -s -o /dev/null -w 'allow=%{http_code}\n' --max-time 5 http://<目标IP>:<PORT_ALLOW>/
   ```
9. 清理测试进程并确认端口列表恢复基线：
   ```bash
   CASE_TMP=/var/tmp/tc-fw-cmd && . $CASE_TMP/env.sh
   sudo kill $(cat $CASE_TMP/pallow.pid) $(cat $CASE_TMP/pctrl.pid) 2>/dev/null
   sleep 1
   ss -ltn | grep -cE ":($PORT_ALLOW|$PORT_CTRL)\b"
   diff $CASE_TMP/before.ports <(sudo firewall-cmd --list-ports); echo "runtime-ports-diff=$?"
   diff $CASE_TMP/before.ports-perm <(sudo firewall-cmd --permanent --list-ports); echo "permanent-ports-diff=$?"
   sudo firewall-cmd --list-all
   rm -rf $CASE_TMP
   ```

## 预期结果

1. 步骤 1：`rpm -q firewalld` 输出版本；`--state` 输出 `running`；默认 zone 为 `public`，其 `services` 含 `ssh`；`env.sh`、`before.ports`、`before.ports-perm`、`before.bootid` 均生成。
2. 步骤 2：`PORT_ALLOW` 与 `PORT_CTRL` 均为非空且互不相同（未被监听、未被 `--query-port` 判为放通、未命中 rich rule），不输出 `pick-failed`；两个端口均处于 `LISTEN`。
3. 步骤 3：`allow=000` 与 `ctrl=000`，两个端口访问均失败，`curl` 退出码非 0（连接被拒绝——firewalld 默认 zone 是 reject 行为，不是超时）。若此处出现 `200`，说明端口选取不当，应重新执行步骤 2。
4. 步骤 4：两条 `--add-port` 均返回 `success`（退出码 0），`--reload` 退出码 0；`--list-ports` 与 `--permanent --list-ports` 均包含 `$PORT_ALLOW/tcp`；`query-allow` 退出码为 0。
5. 步骤 5：`allow=200`（放行生效）；`ctrl=000`、退出码非 0（**无意外放行**）。
6. 步骤 6：
   - `bootid-changed` 退出码为 `0`（确认确实重启）；
   - `systemctl is-active firewalld` 为 `active`；
   - `--list-ports` 与 `--permanent --list-ports` 重启后仍包含 `$PORT_ALLOW/tcp`，`query-allow-after-reboot` 退出码为 0（**`--permanent` 生效**）。
7. 步骤 7：`allow=200`，`ctrl=000`、退出码非 0（放行规则与"无非预期放行"在重启后均成立）。
8. 步骤 8：`--remove-port` 与 `--reload` 退出码均为 0；两个端口列表均不含 `$PORT_ALLOW`；`query-allow-after-remove` 退出码非 0；对端 `allow=000`、退出码非 0。
9. 步骤 9：`ss -ltn` 中无所选端口残留（计数为 0）；`runtime-ports-diff` 与 `permanent-ports-diff` 退出码均为 0；`--list-all` 中 `ports` 为空，`services` 仍为基线值；`$CASE_TMP` 已删除。
