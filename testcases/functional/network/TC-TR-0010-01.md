# TC-TR-0010-01 ｜ 网络配置/DNS/路由与重启保持

| 字段 | 值 |

| 关联需求 | TR-0010（网络基础功能） |

| 功能模块 | 网络 |

| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证静态/DHCP 网络配置、DNS 解析及路由正常，且配置在重启后保持有效。

## 前置条件

1. 具备可配置的网络环境（支持 DHCP 或可配置静态地址）。

## 测试步骤

1. 配置静态地址或 DHCP：使用 `nmcli con mod`（或 NetworkManager / systemd-networkd 配置），并重启网络服务。
2. 验证 DNS 解析：`getent hosts openruyi.cn`（或 `dig` / `nslookup`）。
3. 验证路由：`ip route` 确认默认路由存在。
4. 重启系统后核对：`ip addr`、`ip route`、`getent hosts openruyi.cn`。

## 预期结果

1. 步骤 1：配置生效，接口获得预期地址。
2. 步骤 2：DNS 解析成功，返回正确 IP。
3. 步骤 3：默认路由存在。
4. 步骤 4：重启后配置保持有效，DNS 解析仍正常。
