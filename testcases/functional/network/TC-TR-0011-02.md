# TC-TR-0011-02 ｜ wifi 错误密码拒绝

| 字段 | 值 |
|---|---|

| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证 wifi 使用错误密码连接被拒绝。

## 前置条件

1. 存在可用 wifi 网络（已知 SSID）。
2. 必须先确认存在真实无线网卡：`iw dev` 有输出。仅靠 `nmcli radio wifi` 返回 `enabled` 无法证明具备无线能力。
3. 若设备无无线网卡（如实测 riscv64 物理机，且内核无 `mac80211_hwsim`），本用例不可执行。

## 测试步骤

1. 使用错误密码连接：
   ```bash
   sudo nmcli device wifi connect <SSID> password <错误密码>
   echo $?
   ```
2. 确认连接结果：
   ```bash
   nmcli -t -f ACTIVE,SSID connection show
   nmcli device status
   ```

## 预期结果

1. 步骤 1：连接失败，返回非 0 退出码，提示认证失败（如 `Secrets were required, but not provided`）。
2. 步骤 2：该 SSID 未出现在活动连接中，未获得网络访问。

> 说明：若使用错误密码后连接仍成功，说明接入点未启用认证或 PSK 配置有误，应判为失败并核查 AP 侧配置。
