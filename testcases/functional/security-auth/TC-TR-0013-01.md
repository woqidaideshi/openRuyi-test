# TC-TR-0013-01 ｜ TLS/证书认证

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0013（安全与认证基础功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 安全与认证 |
| 优先级 | P0 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证合法证书完成 TLS 认证/连接，不可信证书被拒绝。

## 前置条件

1. openssl 可用。
2. 准备一份合法（受信 CA 签发）证书与一份不可信证书，并搭建 TLS 测试端点（可用 `openssl s_server`）。

## 测试步骤

1. 使用合法证书连接：`openssl s_client -connect <地址>:<端口> -CAfile <受信CA>`。
2. 使用不可信证书连接：`openssl s_client -connect <地址>:<端口>`（不信任其 CA）。

## 预期结果

1. 步骤 1：握手成功，证书链验证通过。
2. 步骤 2：握手失败，证书验证被拒绝。
