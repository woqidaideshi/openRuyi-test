# TC-TR-0013-01 ｜ TLS/证书认证

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0013（安全与认证基础功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 安全与认证 |
| 优先级 | P0 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证合法证书完成 TLS 认证/连接，不可信证书被拒绝。

## 前置条件

1. 已安装 openssl。
2. 具备可写工作目录（如 `/tmp`）。

## 测试步骤

1. 生成测试证书链（受信 CA、服务端证书、不可信 CA）：
   ```bash
   rm -rf /tmp/tls-test && mkdir -p /tmp/tls-test && cd /tmp/tls-test
   openssl req -x509 -newkey rsa:2048 -keyout ca1.key -out ca1.crt -days 30 -nodes -subj "/CN=TestCA1"
   openssl req -newkey rsa:2048 -keyout server.key -out server.csr -nodes -subj "/CN=localhost"
   openssl x509 -req -in server.csr -CA ca1.crt -CAkey ca1.key -CAcreateserial -out server.crt -days 30
   openssl req -x509 -newkey rsa:2048 -keyout ca2.key -out ca2.crt -days 30 -nodes -subj "/CN=TestCA2"
   ```
2. 启动 TLS 测试端点：
   ```bash
   openssl s_server -accept 4433 -cert server.crt -key server.key -www &
   sleep 1
   ```
3. 使用受信 CA 验证连接（合法证书）：
   ```bash
   echo | openssl s_client -connect 127.0.0.1:4433 -CAfile ca1.crt 2>&1 | grep -E 'Verify return code'
   ```
4. 使用不可信 CA 验证连接（不可信证书）：
   ```bash
   echo | openssl s_client -connect 127.0.0.1:4433 -CAfile ca2.crt 2>&1 | grep -E 'Verify return code'
   ```
5. 关闭测试端点并清理：
   ```bash
   pkill -f 's_server -accept 4433'
   cd /tmp && rm -rf /tmp/tls-test
   ```

## 预期结果

1. 步骤 1：证书链生成成功（CA、服务端证书、不可信 CA 均生成），各 `openssl req/x509` 退出码均为 0。
2. 步骤 2：`s_server` 正常监听 4433 端口。
3. 步骤 3：`Verify return code: 0 (ok)`，握手成功，证书链验证通过。
4. 步骤 4：`Verify return code` 为非 0（实测为 `21 (unable to verify the first certificate)`），证书验证被拒绝。
5. 步骤 5：测试端点已关闭，测试产物清理完毕。
