# TC-TR-0013-04 ｜ 审计记录

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0013（安全与认证基础功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 安全与认证 |
| 优先级 | P0 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证规定安全事件生成完整、可查询的审计记录。

## 前置条件（Setup）

1. auditd 已运行，并已配置审计规则（如 `auditctl -w /etc/passwd -p wa`）。

## 测试步骤（How to test）

1. 触发规定安全事件（如修改受监控文件、失败的登录尝试）。
2. 查询审计记录：`ausearch -f /etc/passwd` 或 `ausearch -m USER_AUTH`。

## 预期结果（Expected Results）

1. 步骤 1：事件发生。
2. 步骤 2：`ausearch` 返回完整审计记录（含事件类型、主体、对象、结果、时间戳）。
