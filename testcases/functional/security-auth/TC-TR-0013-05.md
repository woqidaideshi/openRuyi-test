# TC-TR-0013-05 ｜ 磁盘加密

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0013（安全与认证基础功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 安全与认证 |
| 优先级 | P0 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证磁盘加密卷使用有效密钥可解锁并正常读写，无效密钥无法解锁。

## 前置条件（Setup）

1. cryptsetup 可用；已就绪用于加密的设备。

## 测试步骤（How to test）

1. 创建加密卷：`cryptsetup luksFormat <设备>`。
2. 使用有效密钥解锁：`cryptsetup open <设备> <映射名>`，挂载后读写。
3. 关闭后使用无效密钥解锁：`cryptsetup open <设备> <映射名>` 输入错误密钥。

## 预期结果（Expected Results）

1. 步骤 1：加密卷创建成功。
2. 步骤 2：有效密钥可解锁，挂载读写正常。
3. 步骤 3：无效密钥无法解锁（提示密钥错误）。
