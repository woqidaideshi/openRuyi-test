# TC-TR-0013-05 ｜ 磁盘加密

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0013（安全与认证基础功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 安全与认证 |
| 优先级 | P0 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证磁盘加密卷使用有效密钥可解锁并正常读写，无效密钥无法解锁。

## 前置条件

1. 已安装 cryptsetup，具备 root 权限（sudo）。
2. 具备可写工作目录与足够空间（如 `/tmp`）。

## 测试步骤

1. 创建加密镜像文件：
   ```bash
   rm -rf /tmp/luks-test && mkdir -p /tmp/luks-test
   dd if=/dev/zero of=/tmp/luks-test/luks.img bs=1M count=200 status=none
   ```
2. 格式化加密卷（使用密码）：
   ```bash
   echo -n 'TestPass123' | sudo cryptsetup luksFormat --batch-mode --key-file - /tmp/luks-test/luks.img
   echo $?
   ```
3. 使用有效密钥解锁、创建文件系统并挂载读写：
   ```bash
   echo -n 'TestPass123' | sudo cryptsetup open --key-file - /tmp/luks-test/luks.img crypt_test
   sudo mkfs.ext4 /dev/mapper/crypt_test >/dev/null 2>&1
   sudo mkdir -p /mnt/crypt_test
   sudo mount /dev/mapper/crypt_test /mnt/crypt_test
   echo "data" | sudo tee /mnt/crypt_test/file.txt
   sudo cat /mnt/crypt_test/file.txt
   sudo umount /mnt/crypt_test
   sudo cryptsetup close crypt_test
   ```
4. 使用无效密钥解锁，观察失败：
   ```bash
   echo -n 'WrongPass' | sudo cryptsetup open --key-file - /tmp/luks-test/luks.img crypt_test
   echo $?
   ```
5. 使用有效密钥重新解锁并校验数据完整性：
   ```bash
   echo -n 'TestPass123' | sudo cryptsetup open --key-file - /tmp/luks-test/luks.img crypt_test
   sudo mount /dev/mapper/crypt_test /mnt/crypt_test
   sudo cat /mnt/crypt_test/file.txt
   sudo umount /mnt/crypt_test
   sudo cryptsetup close crypt_test
   ```
6. 清理：
   ```bash
   sudo rmdir /mnt/crypt_test
   rm -rf /tmp/luks-test
   ```

## 预期结果

1. 步骤 2：加密卷创建成功，退出码为 0。
2. 步骤 3：有效密钥解锁成功，文件系统创建、挂载、读写正常，`file.txt` 内容为 `data`。
3. 步骤 4：无效密钥解锁失败，退出码为 `2`，提示 `No key available with this passphrase.`，且**不会**创建 `/dev/mapper/crypt_test` 映射（`dmsetup ls` 中无 `crypt_test`）。
4. 步骤 5：有效密钥重新解锁后数据完整（`file.txt` 内容仍为 `data`）。
5. 步骤 6：清理完毕，无残留映射与文件（`dmsetup ls` 无 `crypt_test`，临时目录已删除）。
