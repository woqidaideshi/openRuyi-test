# TC-TR-0013-03 ｜ PAM 认证授权

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0013（安全与认证基础功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 安全与认证 |
| 优先级 | P0 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 PAM 认证流程正常且授权/限制策略生效。

## 前置条件

1. PAM 配置可用（`/etc/pam.d/`，可临时配置一个测试服务）。

## 测试步骤

1. 使用正确凭据执行认证（如 `login` 或 `su`），触发 PAM 流程。
2. 验证授权/限制策略（如 `pam_limits` 的 ulimit 限制、`pam_deny` 拒绝规则）生效。

## 预期结果

1. 步骤 1：认证成功，PAM 会话正常建立。
2. 步骤 2：授权/限制策略按配置生效（如 ulimit 生效、拒绝规则生效）。
