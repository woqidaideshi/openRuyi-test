# TC-TR-0013-06 ｜ 磁盘加密

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0013（安全与认证基础功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 安全与认证 |
| 优先级 | P0 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证磁盘加密卷使用有效密钥可解锁并正常读写，无效密钥无法解锁。

## 前置条件

1. 已安装 cryptsetup，具备 root 权限。
2. 具备至少 300MB 的可用磁盘空间，用于存放 200MB 镜像文件与其上文件系统的数据。
3. 准备主口令与备用口令两个测试口令，长度不少于 8 位并含字母与数字。

## 测试步骤

1. 生成加密卷载体：执行 `dd if=/dev/zero of=luks.img bs=1M count=200` 创建 200MB 镜像文件。
2. 格式化并读取卷头：执行 `cryptsetup luksFormat luks.img` 把镜像格式化为 LUKS 卷并设置主口令；执行 `cryptsetup luksDump luks.img` 查看版本、加密算法、密钥长度与哈希。
3. 解锁并挂载文件系统：执行 `cryptsetup open luks.img luks-test` 把镜像解锁为映射设备 `/dev/mapper/luks-test`；在映射设备上创建 ext4 文件系统并挂载到 `/mnt/luks-test`。
4. 写入数据并记录校验值：向 `/mnt/luks-test/file.txt` 写入 `luks-data` 并记录 md5，随后卸载并关闭映射。
5. 用错误口令尝试解锁：执行 `cryptsetup open luks.img luks-test` 并输入错误口令，执行 `dmsetup ls` 确认未产生映射。
6. 追加备用口令并复核：
    1. 执行 `cryptsetup luksAddKey luks.img` 为镜像追加第二个密钥槽；
    2. 执行 `cryptsetup luksDump luks.img` 确认密钥槽数量；
    3. 执行 `cryptsetup --test-passphrase open luks.img` 分别用主口令与备用口令校验；
    4. 用备用口令执行 `cryptsetup open luks.img luks-test` 解锁并挂载到 `/mnt/luks-test`；
    5. 执行 `md5sum /mnt/luks-test/file.txt` 复核校验值。
7. 卸载并清理：卸载 `/mnt/luks-test`、执行 `cryptsetup close luks-test` 关闭映射，删除 `luks.img` 与 `/mnt/luks-test`，执行 `dmsetup ls` 确认无残留映射。

## 预期结果

1. 步骤 1：镜像文件生成成功，大小为 209715200 字节。
2. 步骤 2：格式化成功；卷头显示为 LUKS2、AES-XTS 加密、512 位密钥、SHA256 哈希。
3. 步骤 3：解锁成功，映射设备 `/dev/mapper/luks-test` 出现；ext4 文件系统创建成功；挂载到 `/mnt/luks-test` 成功。
4. 步骤 4：写入成功并取得 md5；卸载与关闭均成功，映射设备消失。
5. 步骤 5：解锁失败，提示无可用密钥，退出码非 0；`dmsetup ls` 中无 `luks-test`。
6. 步骤 6：
    1. 追加第二个密钥槽成功；
    2. 密钥槽为 2 个；
    3. 两个口令均通过 `--test-passphrase` 校验；
    4. 备用口令解锁成功且挂载成功；
    5. 复核的 md5 与步骤 4 一致。
7. 步骤 7：`dmsetup ls` 无 `luks-test` 映射，`luks.img` 与 `/mnt/luks-test` 均已删除。
