# TC-TR-0026-02 ｜ strace 系统调用记录

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0026（调试与追踪工具功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 调试与追踪 |
| 优先级 | P2 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 strace 正确记录规定的系统调用、参数、返回值及信号。

## 前置条件

1. 已安装 strace、gcc。
2. 具备可写工作目录（如 `/tmp`）。

## 测试步骤

1. 准备一个会触发 openat/read/write 系统调用的程序：
   ```bash
   cat > /tmp/strace-demo.c <<'EOF'
   #include <stdio.h>
   int main(void) {
       FILE *fp = fopen("/tmp/strace-demo-data", "w");
       if (fp) { fprintf(fp, "hello\n"); fclose(fp); }
       return 0;
   }
   EOF
   gcc -o /tmp/strace-demo /tmp/strace-demo.c
   ```
2. 记录系统调用：
   ```bash
   strace -f -e trace=openat,read,write -o /tmp/strace-demo.log /tmp/strace-demo
   echo $?
   ```
3. 检查日志中的系统调用名、参数与返回值：
   ```bash
   grep -E 'openat|read|write' /tmp/strace-demo.log
   ```
4. 记录信号场景：
   ```bash
   strace -f -o /tmp/strace-demo-sig.log sh -c 'kill -TERM $$'
   grep -E 'SIGTERM' /tmp/strace-demo-sig.log
   ```
5. 清理测试产物：
   ```bash
   rm -f /tmp/strace-demo /tmp/strace-demo.c /tmp/strace-demo-data /tmp/strace-demo.log /tmp/strace-demo-sig.log
   ```

## 预期结果

1. 步骤 2：`strace` 执行完成，退出码为 0。
2. 步骤 3：日志中包含 `openat`、`read`、`write` 调用，参数与返回值完整可读。
3. 步骤 4：日志中记录到 `SIGTERM` 信号及其发送进程信息。
4. 步骤 5：测试产物清理完毕。
