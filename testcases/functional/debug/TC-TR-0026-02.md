# TC-TR-0026-02 ｜ strace 系统调用记录

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0026（调试与追踪工具功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 调试与追踪 |
| 优先级 | P2 |
| 覆盖设备 | KVM (RVA20/RVA23) |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 strace 正确记录规定的系统调用、参数、返回值及信号。

## 前置条件

1. 已安装 strace、gcc。

## 测试步骤

1. 确认 strace 可用：执行 `strace -V`。
2. 编写会触发 openat/read/write 系统调用的 C 程序，内容如下：
   ```bash
   #include <stdio.h>
   int main(void) {
       FILE *fp = fopen("strace-demo-data", "w");
       if (fp) { fprintf(fp, "hello\n"); fclose(fp); }
       return 0;
   }
   ```
3. 编译：执行 `gcc -o strace-demo strace-demo.c`。
4. 记录系统调用到日志文件 `strace-demo.log`：执行 `strace -f -e trace=openat,read,write -o strace-demo.log ./strace-demo`。
5. 检查日志中的系统调用名、参数与返回值：执行 `grep -E 'openat|read|write' strace-demo.log`。
6. 记录信号到日志文件 `strace-signal.log`：执行 `strace -f -o strace-signal.log sh -c 'kill -TERM $$'`。
7. 检查日志中的信号记录：执行 `grep -E 'SIGTERM' strace-signal.log`。
8. 确认无被追踪进程与追踪器残留：执行 `pgrep -x strace-demo` 与 `pgrep -x strace`。
9. 清理：删除 `strace-demo`、`strace-demo.c`、`strace-demo-data`、`strace-demo.log` 与 `strace-signal.log`。

## 预期结果

1. 步骤 1：输出版本号。
2. 步骤 2：源文件 `strace-demo.c` 生成。
3. 步骤 3：编译成功，退出码为 0，生成可执行文件 `strace-demo`。
4. 步骤 4：`strace` 执行完成，退出码为 0，日志文件 `strace-demo.log` 生成。
5. 步骤 5：日志中含 `openat`、`read`、`write` 三类调用，每条均为 `<调用名>(<参数列表>) = <返回值>` 形式；例如 `openat(AT_FDCWD, "strace-demo-data", O_WRONLY|O_CREAT|O_TRUNC, 0666) = 3` 可辨认出路径与打开标志、返回文件描述符 `3`，`write(3, "hello\n", 6) = 6` 可辨认出缓冲区内容与写入长度、返回实际写入字节数。
6. 步骤 6：`strace` 因被追踪进程被信号终止而返回 143。
7. 步骤 7：日志中含 `kill(<进程号>, SIGTERM) = 0`、`--- SIGTERM {si_signo=SIGTERM, si_code=SI_USER, si_pid=<进程号>, si_uid=<用户号>} ---` 与 `+++ killed by SIGTERM +++`；`si_code` 为 `SI_USER` 表示信号由用户进程发送，`si_pid` 与 `si_uid` 给出发送方进程号与用户号。
8. 步骤 8：两条 `pgrep` 均无输出，退出码为 1。
9. 步骤 9：测试产物清理完毕。
