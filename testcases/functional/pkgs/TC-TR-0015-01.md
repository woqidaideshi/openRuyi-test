# TC-TR-0015-01 ｜ tar 归档/列表/解包

## 描述

验证 tar 对规定文件类型的归档、列表与解包正常，内容、目录结构及保留属性正确。

## 前置条件

1. 已安装 tar、coreutils、findutils。
2. 具备可写工作目录与足够磁盘空间。

## 测试步骤

1. 在测试目录下的 `src` 子目录准备测试数据：普通文件、UTF-8 中文名文件、空文件、含空格文件名、二进制文件、多层子目录、符号链接（含断链）、硬链接、权限 `600` 与 `755` 的文件、固定 mtime，并记录文件 md5、关键文件权限位与 mtime 作为基线。
2. 用 `tar -cvf` 将 `src` 目录创建为归档 `test.tar`。
3. 用 `tar -tvf` 查看归档成员列表。
4. 用 `tar -xvf` 将归档解包到测试目录下的 `dest`。
5. 比对解包结果与基线：文件 md5、目录结构、符号链接指向、硬链接 inode、权限位与 mtime。
6. 清理：删除测试目录。

## 预期结果

1. 步骤 1：测试数据生成完整，基线记录完成。
2. 步骤 2：归档创建完成，退出码为 0。
3. 步骤 3：列表显示全部成员，无缺失。
4. 步骤 4：解包完成，退出码为 0。
5. 步骤 5：
   - 文件 md5 与基线一致，目录结构一致；
   - 符号链接指向保留，断链 `broken.link` 仍指向 `/nonexistent-target`（不因目标不存在而判失败）；
   - `hard.txt` 与 `plain.txt` 仍为同一 inode，硬链接关系保留；
   - `plain.txt` 权限为 `600`、`script.sh` 权限为 `755`（可执行位保留），两者 mtime 与归档前一致。
6. 步骤 6：测试目录已删除，无残留。
