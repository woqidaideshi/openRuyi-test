# TC-TR-0015-01 ｜ tar 归档/列表/解包

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0015（归档压缩与基础工具功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 基础命令行工具 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 tar 对规定文件类型的归档、列表与解包正常，内容、目录结构及保留属性正确。

## 前置条件

1. 已安装 tar、coreutils、findutils。
2. 具备可写工作目录与足够磁盘空间（如 `/tmp`）。

## 测试步骤

1. 准备测试数据（普通文件、UTF-8 中文名、空文件、含空格文件名、二进制、多层子目录、符号链接（含断链）、硬链接、特殊权限、可执行文件、固定时间戳）：
   ```bash
   CASE_TMP=/tmp/tc-archive && rm -rf $CASE_TMP && mkdir -p $CASE_TMP/src/sub
   echo "hello" > $CASE_TMP/src/plain.txt
   echo "中文内容" > $CASE_TMP/src/中文名.txt
   touch $CASE_TMP/src/empty.txt
   echo "space" > "$CASE_TMP/src/with space.txt"
   dd if=/dev/urandom of=$CASE_TMP/src/bin.dat bs=1024 count=1024 status=none
   echo "nested" > $CASE_TMP/src/sub/nested.txt
   ln -s ../plain.txt $CASE_TMP/src/sub/link.txt
   ln -s /nonexistent-target $CASE_TMP/src/broken.link
   ln $CASE_TMP/src/plain.txt $CASE_TMP/src/hard.txt
   chmod 600 $CASE_TMP/src/plain.txt
   printf '#!/bin/sh\necho hi\n' > $CASE_TMP/src/script.sh
   chmod 755 $CASE_TMP/src/script.sh
   touch -d '2020-01-02 03:04:05' $CASE_TMP/src/plain.txt
   cd $CASE_TMP && find src -type f -exec md5sum {} + | sort -k2 > before.md5
   stat -c '%a %Y' src/plain.txt  > before.plain.attr
   stat -c '%a %Y' src/script.sh  > before.script.attr
   ```
2. 创建归档：
   ```bash
   cd $CASE_TMP && tar -cvf test.tar src
   ```
3. 列表查看归档内容：
   ```bash
   tar -tvf $CASE_TMP/test.tar | head
   ```
4. 解包恢复：
   ```bash
   mkdir -p $CASE_TMP/dest
   tar -xvf $CASE_TMP/test.tar -C $CASE_TMP/dest
   ```
5. 校验解包结果（内容、目录结构、符号链接、权限、时间戳）：
   ```bash
   cd $CASE_TMP/dest && find src -type f -exec md5sum {} + | sort -k2 > $CASE_TMP/after.md5
   diff $CASE_TMP/before.md5 $CASE_TMP/after.md5
   ls -l $CASE_TMP/dest/src/sub/link.txt $CASE_TMP/dest/src/broken.link
   stat -c '%n %a %Y' $CASE_TMP/dest/src/plain.txt $CASE_TMP/dest/src/script.sh
   diff $CASE_TMP/before.plain.attr  <(stat -c '%a %Y' $CASE_TMP/dest/src/plain.txt)
   diff $CASE_TMP/before.script.attr <(stat -c '%a %Y' $CASE_TMP/dest/src/script.sh)
   ```
6. 清理测试数据：
   ```bash
   rm -rf $CASE_TMP
   ```

## 预期结果

1. 步骤 1：测试数据生成成功，`before.md5` 正常生成。
2. 步骤 2：归档创建成功，退出码为 0。
3. 步骤 3：列表正常显示归档成员，无缺失。
4. 步骤 4：解包成功，退出码为 0。
5. 步骤 5：
   - `diff` 无差异：解包后文件内容与归档前完全一致；
   - `link.txt` 显示 `-> ../plain.txt`：正常符号链接保留；
   - `broken.link` 显示 `-> /nonexistent-target`：**断链符号链接同样保留**（不可因目标不存在而判失败）；
   - `plain.txt` 权限位 `600`、`script.sh` 权限位 `755`：权限属性（含可执行位）保留；
   - `hard.txt` 与 `plain.txt` 仍为同一 inode（`stat -c %i` 两者相等）：硬链接关系保留；
   - 两个 `diff` 均无输出：`plain.txt` 与 `script.sh` 的**权限位与 mtime（`%Y`）均与归档前完全一致**。
6. 步骤 6：测试数据清理完毕。
