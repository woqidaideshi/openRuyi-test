## 描述

验证 coreutils 规定文件操作（创建/复制/移动/链接/删除/权限修改）的执行结果、退出码与权限控制符合预期。

> `util-linux` 相关工具已拆分到 `TC-TR-0015-05` 验证，本用例只覆盖 coreutils。

## 前置条件

1. 已安装 coreutils。
2. 具备可写工作目录（如 `/tmp`）。

## 测试步骤

1. 创建、复制、移动、链接、删除文件并记录退出码：
   ```bash
   rm -rf /tmp/fileops-test && mkdir -p /tmp/fileops-test/d1
   echo "mkdir:$?"
   echo data > /tmp/fileops-test/d1/a.txt
   cp /tmp/fileops-test/d1/a.txt /tmp/fileops-test/d1/b.txt; echo "cp:$?"
   mv /tmp/fileops-test/d1/b.txt /tmp/fileops-test/d1/c.txt; echo "mv:$?"
   ln -s a.txt /tmp/fileops-test/d1/link.txt; echo "ln-s:$?"
   ln /tmp/fileops-test/d1/a.txt /tmp/fileops-test/d1/hard.txt; echo "ln:$?"
   rm /tmp/fileops-test/d1/c.txt; echo "rm:$?"
   ```
2. 修改权限并核对权限位：
   ```bash
   chmod 600 /tmp/fileops-test/d1/a.txt; echo "chmod600:$?"
   stat -c '%a %n' /tmp/fileops-test/d1/a.txt
   chmod 755 /tmp/fileops-test/d1; echo "chmod755:$?"
   stat -c '%a %n' /tmp/fileops-test/d1
   ```
3. 权限控制校验（普通用户无法删除 root 属主目录内的文件）：
   ```bash
   sudo mkdir -p /tmp/fileops-test/rootdir
   sudo touch /tmp/fileops-test/rootdir/rootfile
   sudo chmod 755 /tmp/fileops-test/rootdir
   rm /tmp/fileops-test/rootdir/rootfile; echo "rm-root:$?"
   ls -l /tmp/fileops-test/rootdir/rootfile
   ```
   > 注意：第 3 步必须以**非 root 用户**（如 `openruyi`）执行；若以 root 执行则 `rm` 必成功，无法验证权限控制。
4. 清理测试数据：
   ```bash
   sudo rm -rf /tmp/fileops-test
   ```

## 预期结果

1. 步骤 1：`mkdir`、`cp`、`mv`、`ln -s`、`ln`、`rm` 退出码均为 0，操作结果正确。
2. 步骤 2：`chmod` 退出码均为 0，`stat` 显示 `a.txt` 权限为 `600`、`d1` 权限为 `755`（权限位与设置值一致）。
3. 步骤 3：`rm` 返回非 0 退出码（实测为 `1`）并提示 `Permission denied`（实测输出：`rm: cannot remove '.../rootfile': Permission denied`），`rootfile` 仍存在且属主为 `root`（权限控制正确）。
4. 步骤 4：测试数据清理完毕。
