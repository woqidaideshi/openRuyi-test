## 描述

验证 coreutils 规定文件操作（创建/复制/移动/链接/删除/权限修改）的执行结果、退出码与权限控制符合预期。

## 前置条件

1. 已安装 coreutils。
2. 具备可写工作目录。

## 测试步骤

1. 在测试目录下依次执行创建目录、创建文件、复制、移动、创建符号链接、创建硬链接、删除文件。
2. 用 `chmod` 将文件权限改为 `600`、目录权限改为 `755`，并用 `stat` 核对权限位。
3. 权限控制校验：在 `sudo` 权限下创建一个属主为 `root` 的目录及其内的文件，再以普通用户尝试删除该文件。
4. 清理：在 `sudo` 权限下删除属主为 `root` 的目录与其内文件，再删除测试目录。

## 预期结果

1. 步骤 1：`mkdir`、`cp`、`mv`、`ln -s`、`ln`、`rm` 退出码均为 0，操作结果与预期一致。
2. 步骤 2：`chmod` 退出码均为 0；`stat` 显示文件权限为 `600`、目录权限为 `755`。
3. 步骤 3：`rm` 退出码非 0，提示 `Permission denied`；该文件仍存在且属主为 `root`。
4. 步骤 4：测试目录已删除，无残留。
