# TC-TR-0015-02 ｜ gzip/xz/zstd 压缩解压

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0015（归档压缩与基础工具功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 基础命令行工具 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 gzip/xz/zstd 压缩、解压及格式检查正常，处理前后内容校验一致。

## 前置条件

1. 已安装 gzip、xz、zstd。
2. 具备可写工作目录（如 `/tmp`）。

## 测试步骤

1. 准备测试文件并记录校验和：
   ```bash
   rm -rf /tmp/compress-test && mkdir -p /tmp/compress-test
   dd if=/dev/urandom of=/tmp/compress-test/data.bin bs=1M count=4 status=none
   md5sum /tmp/compress-test/data.bin
   ```
2. 分别用 gzip、xz、zstd 压缩（`-k` 保留原文件），并记录退出码：
   ```bash
   gzip -k /tmp/compress-test/data.bin; echo "gzip:$?"
   xz -k /tmp/compress-test/data.bin; echo "xz:$?"
   zstd -q -k /tmp/compress-test/data.bin; echo "zstd:$?"
   ```
3. 用对应命令解压恢复（输出到独立文件），并记录退出码：
   ```bash
   gzip -dc /tmp/compress-test/data.bin.gz > /tmp/compress-test/data.gzip.out; echo "gunzip:$?"
   xz -dc /tmp/compress-test/data.bin.xz > /tmp/compress-test/data.xz.out; echo "unxz:$?"
   zstd -dc /tmp/compress-test/data.bin.zst > /tmp/compress-test/data.zstd.out; echo "unzstd:$?"
   ```
4. 用格式检查命令校验，并记录退出码：
   ```bash
   gzip -t /tmp/compress-test/data.bin.gz; echo "gzip-t:$?"
   xz -t /tmp/compress-test/data.bin.xz; echo "xz-t:$?"
   zstd -t /tmp/compress-test/data.bin.zst; echo "zstd-t:$?"
   ```
5. 对比解压后文件与原始文件校验和：
   ```bash
   md5sum /tmp/compress-test/data.bin /tmp/compress-test/data.gzip.out /tmp/compress-test/data.xz.out /tmp/compress-test/data.zstd.out
   ```
6. 验证“归档 + 压缩”组合包（`tar.gz` / `tar.xz` / `tar.zst`）：
   ```bash
   cd /tmp/compress-test && mkdir -p pkgsrc && echo combo > pkgsrc/combo.txt
   tar -czf src.tar.gz pkgsrc;          echo "tar_gz:$?"
   tar -cJf src.tar.xz pkgsrc;          echo "tar_xz:$?"
   tar --zstd -cf src.tar.zst pkgsrc;   echo "tar_zstd:$?"
   mkdir -p d_gz d_xz d_zst
   tar -xzf src.tar.gz -C d_gz && tar -xJf src.tar.xz -C d_xz && tar --zstd -xf src.tar.zst -C d_zst
   for d in d_gz d_xz d_zst; do
     printf '%s: ' "$d"; (cd $d && find . -type f -exec md5sum {} + | awk '{print $1}' | sort | tr '\n' ' '); echo
   done
   printf 'src: '; (find pkgsrc -type f -exec md5sum {} + | awk '{print $1}' | sort | tr '\n' ' '); echo
   ```
7. 清理测试数据：
   ```bash
   rm -rf /tmp/compress-test
   ```

## 预期结果

1. 步骤 1：测试文件生成成功。
2. 步骤 2：三种格式压缩成功，退出码均为 0。
3. 步骤 3：三种格式解压成功，退出码均为 0。
4. 步骤 4：三种格式校验通过（`gzip -t` / `xz -t` / `zstd -t` 退出码均为 0）。
5. 步骤 5：三个解压产物与原始 `data.bin` 的 md5 完全一致。
6. 步骤 6：
   - 三个 `tar` 组合命令退出码均为 0；
   - `tar -tzf` / `tar -tJf` / `tar --zstd -tf` 均能正常列出成员；
   - 三份解包结果与源目录的 **md5 值集合**完全一致（实测均为单一 md5 值，三者相同）；
     > 比 md5 时只比对**摘要值**（`awk '{print $1}'`），不要直接比对 `md5sum` 整行——不同目录下路径前缀不同（`./pkgsrc/…` vs `pkgsrc/…`），整行比对会误判为不一致。
7. 步骤 7：测试数据清理完毕。
