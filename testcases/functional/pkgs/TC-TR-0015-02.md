# TC-TR-0015-02 ｜ gzip/xz/zstd 压缩解压

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0015（归档压缩与基础工具功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 基础命令行工具 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 gzip/xz/zstd 压缩、解压及格式检查正常，处理前后内容校验一致。

## 前置条件

1. 已安装 gzip、xz、zstd。
2. 具备可写工作目录。

## 测试步骤

1. 生成 4MB 随机文件 `data.bin`，并记录其 md5。
2. 分别执行 `gzip -k data.bin`、`xz -k data.bin`、`zstd -k data.bin` 压缩该文件，保留原文件。
3. 分别执行 `gzip -dc data.bin.gz > data.gzip.bin`、`xz -dc data.bin.xz > data.xz.bin`、`zstd -dc data.bin.zst > data.zstd.bin` 解压到三个独立文件。
4. 分别执行 `gzip -t data.bin.gz`、`xz -t data.bin.xz`、`zstd -t data.bin.zst` 校验压缩包完整性。
5. 比对原始文件与三个解压产物的 md5。
6. 验证归档加压缩组合：执行 `tar -czf test.tar.gz <目录>`、`tar -cJf test.tar.xz <目录>`、`tar --zstd -cf test.tar.zst <目录>` 生成 `tar.gz` / `tar.xz` / `tar.zst`，分别列出成员并解包到三个目录。
7. 清理：删除全部测试文件与目录。

> 步骤 6 比对 md5 时只比摘要值，不要比 `md5sum` 整行：不同目录的路径前缀不同（`./pkgsrc/…` 与 `pkgsrc/…`），整行比对会误判为不一致。

## 预期结果

1. 步骤 1：文件生成完成，md5 记录完成。
2. 步骤 2：三种格式压缩完成，退出码均为 0。
3. 步骤 3：三种格式解压完成，退出码均为 0。
4. 步骤 4：三种格式校验通过，退出码均为 0。
5. 步骤 5：三个解压产物的 md5 与原始 `data.bin` 一致。
6. 步骤 6：三个组合包生成与列出成员均完成，退出码均为 0；三份解包结果的文件 md5 值集合与源目录一致。
7. 步骤 7：测试文件与目录均已删除，无残留。
