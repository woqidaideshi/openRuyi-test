# TC-TR-0024-01 ｜ 显示器基础显示

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0024（显示器正常显示） |
| 测试类型 | 功能测试 |
| 功能模块 | 桌面与显示 |
| 优先级 | P2 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证启动时系统日志在显示器上滚动显示，带桌面时登录管理器可显示（本期最低验收）。

## 前置条件（Setup）

1. 显示器已连接。

## 测试步骤（How to test）

1. 启动系统。
2. 观察启动过程中显示器输出（滚动日志）。
3. 带桌面形态下，观察登录管理器显示。

## 预期结果（Expected Results）

1. 步骤 2：启动时系统日志在显示器上滚动显示。
2. 步骤 3：带桌面则显示登录管理器（最低验收；具体内容待图形化方向补充）。
