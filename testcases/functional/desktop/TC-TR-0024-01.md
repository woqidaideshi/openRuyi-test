# TC-TR-0024-01 ｜ 启动阶段显示器正常输出

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0024（显示器正常显示） |
| 测试类型 | 功能测试 |
| 功能模块 | 桌面与显示 |
| 优先级 | P2 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证系统从上电到启动完成期间显示器有基础输出：显示器正常点亮，固件与引导阶段有显示，内核日志正常滚动；启动完成后按镜像类型显示文本登录提示符或图形登录管理器；控制台输出随操作刷新。

## 前置条件

1. 已连接显示器并正常供电，或 qemu 配置了显示设备与显示输出。
2. 系统可正常引导。
3. 若为桌面版镜像，已安装并启用显示管理器（如 `sddm`），可随系统启动。

## 测试步骤

1. 接通显示器电源后给系统上电，观察显示器状态与信号锁定情况。
2. 观察显示器在固件与引导加载程序阶段的输出。
3. 观察显示器在内核启动阶段的日志滚动情况。
4. 启动完成后观察屏幕，按镜像类型判定：
    - 无桌面环境：确认停在文本登录提示符，以 `openruyi` 登录。
    - 桌面环境：确认自动进入图形登录管理器，观察界面元素与显示质量，移动鼠标、切换焦点观察画面响应；再在图形界面中的终端执行以下命令，确认显示管理器与图形会话：
        - `systemctl is-active sddm`
        - `loginctl list-sessions`
        - `journalctl -b -u sddm | tail`
5. 登录后（无桌面镜像为文本控制台，桌面镜像为图形界面中的终端）查看显示设备与连接器状态，执行以下命令：
    - `ls /dev/dri`
    - `grep -H . /sys/class/drm/card*-*/status`
    - `wc -c /sys/class/drm/card*-*/edid`
    - `cat /sys/class/drm/card*-*/modes`
6. 在控制台执行 `ls -l /` 与 `dmesg | tail`，观察屏幕内容刷新情况。

## 预期结果

1. 步骤 1：显示器点亮并锁定信号，无"无信号"或"超出范围"提示。
2. 步骤 2：固件与引导加载程序阶段有正常显示输出，无乱码。
3. 步骤 3：内核日志在屏幕上连续滚动，字体清晰，无花屏、闪烁、中途黑屏或输出中断。
4. 步骤 4：
    - 无桌面环境：屏幕显示文本登录提示符（`login:`），输入 `openruyi` 账号与口令后进入 shell，提示与回显正常，无花屏、无内容错位；
    - 桌面环境：启动完成后自动显示登录管理器，不停留在文本控制台；背景、登录框、用户名与输入框、功能按钮等元素完整，无错位、截断或缺失，字体与图标清晰；鼠标移动与焦点切换即时响应，无卡顿、花屏或闪烁；显示管理器服务已启动，`loginctl list-sessions` 可见位于 `seat0` 的图形会话，`journalctl` 未出现显示初始化失败类错误。
5. 步骤 5：
    - `/dev/dri` 下存在 `card*` 设备；
    - 已接入显示器的连接器状态为 `connected`；
    - EDID 长度为 128 或 256 字节；
    - `modes` 含该显示器的原生分辨率。

    带 BMC 的机器 VGA 连接器未接显示器时也会显示 `connected`，但 EDID 为 0 字节且 `modes` 仅有 `1024x768`、`800x600`、`640x480` 类兜底分辨率，此类环境下以屏幕实际输出为准。
6. 步骤 6：输出随命令执行即时刷新，无残影、卡住或内容错位。
