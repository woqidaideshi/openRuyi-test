# TC-TR-0009-04 ｜ 软 RAID0 创建与组装

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证软 RAID0（条带、无冗余）的创建与组装，数据在停止并重新组装后保持一致。RAID0 不提供冗余，因此不涉及降级与重建。

## 前置条件

1. RISC-V 平台，已安装 mdadm。
2. 具备两块 600MB 可写的 loop 镜像（默认方案，不占用物理盘、不涉及固件分区）。
3. 若必须使用物理盘，必须先确认该盘**不含固件/引导分区**。

## 测试步骤

1. 准备两块 loop 成员盘：
   ```bash
   rpm -q mdadm
   sudo mkdir -p /srv/tc-md
   sudo truncate -s 600M /srv/tc-md/m1.img /srv/tc-md/m2.img
   L1=$(sudo losetup -f --show /srv/tc-md/m1.img)
   L2=$(sudo losetup -f --show /srv/tc-md/m2.img)
   echo "L1=$L1 L2=$L2"
   ```
2. 创建 RAID0 并查看阵列状态：
   ```bash
   sudo mdadm --create /dev/md0 --level=0 --raid-devices=2 "$L1" "$L2" --run
   cat /proc/mdstat
   ```
3. 创建文件系统并挂载读写：
   ```bash
   sudo mkfs.ext4 /dev/md0 > /dev/null 2>&1; echo "mkfs:$?"
   sudo mkdir -p /mnt/md0
   sudo mount /dev/md0 /mnt/md0; echo "mount:$?"
   echo "raid0-data" | sudo tee /mnt/md0/file0.txt
   md5sum /mnt/md0/file0.txt
   sudo umount /mnt/md0
   ```
4. 停止并重新组装后校验数据：
   ```bash
   sudo mdadm --stop /dev/md0
   sudo mdadm --assemble /dev/md0 "$L1" "$L2"
   sudo mount /dev/md0 /mnt/md0; echo "mount:$?"
   sudo cat /mnt/md0/file0.txt
   sudo umount /mnt/md0
   sudo mdadm --stop /dev/md0
   ```
5. 清理（擦除超级块并释放 loop 设备）：
   ```bash
   sudo mdadm --zero-superblock "$L1" "$L2"
   sudo losetup -d "$L1" "$L2"
   sudo rm -rf /srv/tc-md
   sudo rmdir /mnt/md0
   ```

## 预期结果

1. 步骤 1：mdadm 已安装，两块 loop 设备创建成功（`L1`、`L2` 均非空）。
2. 步骤 2：
   - RAID0 创建成功，退出码为 0；
   - `/proc/mdstat` 显示 `md0 : active raid0`，可用块数约为单盘的两倍（条带拼接）；
   - RAID0 无冗余，`/proc/mdstat` 中不出现 `[U_]` 成员状态位。
3. 步骤 3：`mkfs` 与 `mount` 退出码均为 0，`md5sum` 输出正常。
4. 步骤 4：
   - `mdadm --assemble` 提示 `has been started with 2 drives`；
   - 重新挂载退出码为 0；
   - `file0.txt` 内容为 `raid0-data`，md5 与步骤 3 一致。
5. 步骤 5：清理完毕，`losetup -a` 无残留，`/proc/mdstat` 无 `md0`，`/srv/tc-md` 已删除。
