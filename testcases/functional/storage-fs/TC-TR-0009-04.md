# TC-TR-0009-04 ｜ 软 RAID0 创建与组装

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证软 RAID0（条带、无冗余）的创建与组装，数据在停止并重新组装后保持一致。RAID0 不提供冗余，因此不涉及降级与重建。

## 前置条件

1. RISC-V 平台，已安装 mdadm。
2. 具备两块 600MB 可写的 loop 镜像（默认方案，不占用物理盘、不涉及固件分区）。
3. 若必须使用物理盘，必须先确认该盘**不含固件/引导分区**。

## 测试步骤

1. 准备两块 600MB 的 loop 成员盘（用镜像文件挂为 loop 设备，记作 `$L1`、`$L2`）。
2. 用两块成员盘创建 RAID0 阵列到 `/dev/md0`（`mdadm --create /dev/md0 --level=0`），并查看 `/proc/mdstat` 中的阵列状态。
3. 在阵列上创建 ext4 文件系统并挂载到 `/mnt/md0`，写入 `file0.txt`，记录 md5。
4. 停止阵列后用 `mdadm --assemble` 重新组装，重新挂载到 `/mnt/md0` 并复核文件内容与 md5。
5. 清理：
   - 停止阵列（`mdadm --stop`）；
   - 用 `mdadm --zero-superblock` 擦除成员盘超级块；
   - 用 `losetup -d` 释放 loop 设备；
   - 删除镜像文件与挂载点目录 `/mnt/md0`。
   > 阵列未停止时 `mdadm --zero-superblock` 会报 `Couldn't open … for write - not zeroing`，超级块实际未被清除；`losetup -d` 也会返回成功但设备仍留在 `losetup -a` 中。

## 预期结果

1. 步骤 1：两块 loop 设备创建成功。
2. 步骤 2：
   - RAID0 创建成功，`/proc/mdstat` 显示 `md0 : active raid0`；
   - 可用块数约为单盘的两倍；
   - 因无冗余，不出现 `[U_]` 成员状态位。
3. 步骤 3：文件系统创建与挂载均成功，`file0.txt` 内容为 `raid0-data`，md5 记录成功。
4. 步骤 4：
   - `mdadm --assemble` 提示 `has been started with 2 drives`；
   - 重新挂载成功；
   - `file0.txt` 内容与 md5 与步骤 3 一致。
5. 步骤 5：
   - 阵列已停止，`/proc/mdstat` 无 `md0`；
   - 成员盘超级块已擦除；
   - loop 设备已释放，无残留；
   - 镜像文件与挂载点目录 `/mnt/md0` 已删除。
