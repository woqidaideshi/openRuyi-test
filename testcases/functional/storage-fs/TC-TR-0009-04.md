# TC-TR-0009-04 ｜ NFS/CIFS 客户端

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证 NFS/CIFS 客户端能连接受支持服务器，完成挂载、授权读写与卸载。

## 前置条件

1. 受支持的 NFS 服务端与 CIFS(SMB) 服务端可达，已配置共享目录/共享名与授权账户。
2. 已安装 nfs-utils、cifs-utils。
3. 已确认服务端端口可达（`showmount -e <NFS服务器>`）。

> 验证提示：若无外部服务器，可在**同一机器**上搭建本地 NFS/Samba 服务端，通过 `127.0.0.1` 挂载，同样可完整覆盖客户端代码路径。

## 测试步骤

1. 确认工具与服务端可达性：
   ```bash
   rpm -q nfs-utils cifs-utils
   showmount -e <NFS服务器>
   ```
2. 挂载 NFS 共享：
   ```bash
   sudo mkdir -p /mnt/nfs
   sudo mount -t nfs <NFS服务器>:<导出路径> /mnt/nfs
   echo $?
   findmnt -n -o SOURCE,FSTYPE /mnt/nfs
   ```
3. NFS 授权读写：
   ```bash
   echo "nfs-data" | sudo tee /mnt/nfs/file.txt
   sudo cat /mnt/nfs/file.txt
   sudo rm /mnt/nfs/file.txt
   sudo umount /mnt/nfs
   ```
4. 挂载 CIFS 共享：
   ```bash
   sudo mkdir -p /mnt/cifs
   sudo mount -t cifs //<服务器>/<共享> /mnt/cifs -o user=<账户>,password=<密码>
   echo $?
   findmnt -n -o SOURCE,FSTYPE,OPTIONS /mnt/cifs
   ```
5. CIFS 授权读写：
   ```bash
   echo "cifs-data" | sudo tee /mnt/cifs/file.txt
   sudo cat /mnt/cifs/file.txt
   sudo rm /mnt/cifs/file.txt
   sudo umount /mnt/cifs
   ```
6. 错误密码重试（应失败）：
   ```bash
   sudo mount -t cifs //<服务器>/<共享> /mnt/cifs -o user=<账户>,password=wrong
   echo $?
   ```
7. 清理：
   ```bash
   sudo rmdir /mnt/nfs /mnt/cifs
   ```

## 预期结果

1. 步骤 2：NFS 挂载成功，退出码为 0，`findmnt` 显示 `FSTYPE` 为 `nfs`（实测 `vers=3` 与默认协商均可）。
2. 步骤 3：NFS 创建、读取、删除文件均成功（`write/rm/umount` 退出码均为 0）。
3. 步骤 4：CIFS 挂载成功，退出码为 0；不指定 `vers=` 时自动协商到 `vers=3.1.1`。
4. 步骤 5：CIFS 创建、读取、删除文件均成功。
5. 步骤 6：错误密码挂载失败，退出码非 0（实测 `32`），提示 `mount error(13): Permission denied`。
6. 步骤 7：清理完毕，无残留挂载点。
