# TC-TR-0009-03 ｜ 软 RAID 创建组装恢复

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证软 RAID 受支持级别（如 RAID1）的创建、组装及适用的降级恢复正常。

## 前置条件（Setup）

1. RISC-V 平台，已就绪多块可用存储设备。
2. 已安装 mdadm。

## 测试步骤（How to test）

1. 创建受支持级别 RAID：`mdadm --create /dev/md0 --level=raid1 --raid-devices=2 <设备1> <设备2>`。
2. 重新组装：`mdadm --assemble /dev/md0 <设备1> <设备2>`。
3. 降级恢复：`mdadm --fail /dev/md0 <设备2>` + `mdadm --remove /dev/md0 <设备2>`，加入替换盘后重建。

## 预期结果（Expected Results）

1. 步骤 1：RAID 创建成功，`cat /proc/mdstat` 显示阵列状态正常。
2. 步骤 2：组装成功。
3. 步骤 3：降级后阵列仍可用，替换盘后重建完成、状态恢复正常。
