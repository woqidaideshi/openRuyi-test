# TC-TR-0009-03 ｜ LVM 卷管理

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 LVM 能完成规定的卷管理操作（PV/VG/LV 创建、扩展/缩减、挂载读写）。

## 前置条件

1. RISC-V 平台，具备可写工作目录与至少 2GB 可用空间。
2. 已安装 lvm2。

## 测试步骤

1. 创建测试镜像并挂为 loop 设备：
   ```bash
   CASE_TMP=/tmp/tc-lvm && rm -rf $CASE_TMP && mkdir -p $CASE_TMP
   truncate -s 2G $CASE_TMP/disk.img
   DEV=$(sudo losetup -f --show $CASE_TMP/disk.img)
   echo "DEV=$DEV"
   rpm -q lvm2
   ```
   > 若改用真实空闲盘/分区，把 `DEV` 直接设为该设备（如 `/dev/vdb`）并跳过镜像创建，同时先用 `findmnt -n -o SOURCE /` 确认它不是根文件系统所在盘。
2. 创建 PV / VG / LV：
   ```bash
   sudo pvcreate -y "$DEV"
   sudo vgcreate vg_test "$DEV"
   sudo lvcreate -L 512M -n lv_test vg_test
   ```
3. 在 LV 上创建文件系统并挂载读写：
   ```bash
   sudo mkfs.ext4 /dev/vg_test/lv_test >/dev/null 2>&1
   sudo mkdir -p /mnt/lv_test
   sudo mount /dev/vg_test/lv_test /mnt/lv_test
   echo "lvm-data" | sudo tee /mnt/lv_test/file.txt
   sudo cat /mnt/lv_test/file.txt
   df -h /mnt/lv_test
   ```
4. 扩展 LV 与文件系统并核对数据：
   ```bash
   sudo lvextend -L +512M /dev/vg_test/lv_test
   sudo resize2fs /dev/vg_test/lv_test
   sudo lvs --noheadings -o lv_size /dev/vg_test/lv_test
   df -h /mnt/lv_test
   sudo cat /mnt/lv_test/file.txt
   ```
5. 缩减 LV 与文件系统（先缩文件系统、再缩 LV）并核对数据：
   ```bash
   sudo umount /mnt/lv_test
   sudo e2fsck -fy /dev/vg_test/lv_test; echo "e2fsck:$?"
   sudo resize2fs /dev/vg_test/lv_test 512M; echo "resize2fs:$?"
   sudo lvreduce -L 512M -f /dev/vg_test/lv_test; echo "lvreduce:$?"
   sudo lvs --noheadings -o lv_size /dev/vg_test/lv_test
   sudo mount /dev/vg_test/lv_test /mnt/lv_test
   df -h /mnt/lv_test
   sudo cat /mnt/lv_test/file.txt
   ```
   > 缩减必须**先缩文件系统、再缩 LV**。
6. 清理（卸载、删除 LV/VG/PV，释放 loop 设备）：
   ```bash
   sudo umount /mnt/lv_test
   sudo lvremove -y /dev/vg_test/lv_test
   sudo vgremove -y vg_test
   sudo pvremove -y "$DEV"
   sudo rmdir /mnt/lv_test
   sudo losetup -d "$DEV"
   rm -rf $CASE_TMP
   ```

## 预期结果

1. 步骤 1：镜像创建成功，`DEV` 指向 `/dev/loopN`，lvm2 已安装。
2. 步骤 2：`pvcreate` / `vgcreate` / `lvcreate` 均成功，退出码为 0。
3. 步骤 3：LV 上文件系统创建、挂载、读写正常，`file.txt` 内容为 `lvm-data`，`df -h` 显示容量约 488M。
4. 步骤 4：
   - `lvextend` / `resize2fs` 退出码为 0；
   - `lvs` 显示 LV 尺寸扩展到 `1.00g`（确认 LV 本身已扩容）；
   - `df -h` 显示容量增加到约 991M（增加 512M）；
   - 原有数据 `lvm-data` 完整可读。
5. 步骤 5：
   - `e2fsck` / `resize2fs` / `lvreduce` 退出码均为 0；
   - `lvs` 显示 LV 尺寸缩减为 `512.00m`（直接确认 LV 本身已缩小）；
   - `df -h` 显示容量缩减回约 488M；
   - 重新挂载后 `file.txt` 仍为 `lvm-data`（缩减不损坏数据）。
6. 步骤 6：清理完成，无残留 PV/VG/LV，`losetup -a` 无残留，镜像目录已删除。
