# TC-TR-0009-03 ｜ LVM 卷管理

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 LVM 能完成规定的卷管理操作（PV/VG/LV 创建、扩展/缩减、挂载读写）。

## 前置条件

1. RISC-V 平台，具备可写工作目录与至少 2GB 可用空间。
2. 已安装 lvm2。

## 测试步骤

1. 准备测试设备：创建 2GB 镜像文件并挂为 loop 设备（记作 `$DEV`）。若改用真实空闲盘/分区，直接使用其设备路径，并先用 `findmnt` 查看根文件系统所在设备，避免误用在用盘。
2. 创建 PV / VG / LV：依次 `pvcreate`、`vgcreate`、`lvcreate`，创建一个 512MB 的 LV。
3. 在 LV 上创建 ext4 文件系统并挂载到 `/mnt/lv_test`，写入 `file.txt` 后用 `df -h` 查看文件系统容量。
4. 扩展 LV 并同步扩展文件系统：
   - 用 `lvextend` 扩展 LV 512MB，再用 `resize2fs` 同步扩展文件系统；
   - 用 `lvs` 查看 LV 尺寸、用 `df -h` 查看文件系统容量；
   - 复核数据。
5. 缩减文件系统与 LV：
   - 用 `resize2fs` 缩减文件系统，再用 `lvreduce` 缩减 LV；
   - 用 `lvs` 查看 LV 尺寸、用 `df -h` 查看文件系统容量；
   - 重新挂载到 `/mnt/lv_test` 后复核数据。
6. 清理：
   - 卸载 `/mnt/lv_test`；
   - 依次删除 LV、VG、PV；
   - 用 `losetup -d` 释放 loop 设备；
   - 删除镜像文件与挂载点目录 `/mnt/lv_test`。
   > 顺序不能颠倒：LV / VG / PV 未删除时 `losetup -d` 返回成功但设备仍被占用（`losetup -a` 依旧能看到），实际没释放。

## 预期结果

1. 步骤 1：镜像创建成功，`$DEV` 指向 `/dev/loopN`，且不是根文件系统所在设备。
2. 步骤 2：`pvcreate`、`vgcreate`、`lvcreate` 均成功，无报错。
3. 步骤 3：文件系统创建、挂载、读写均正常，`file.txt` 内容为 `lvm-data`，`df -h` 显示文件系统容量约 488M。
4. 步骤 4：
   - `lvs` 显示 LV 尺寸扩展到 `1.00g`；
   - `df -h` 显示文件系统容量增加到约 991M；
   - 原有数据 `lvm-data` 完整可读。
5. 步骤 5：
   - `lvs` 显示 LV 尺寸缩减为 `512.00m`；
   - `df -h` 显示文件系统容量缩减回约 488M；
   - 重新挂载后 `file.txt` 仍为 `lvm-data`（缩减未损坏数据）。
6. 步骤 6：
   - `/mnt/lv_test` 已卸载；
   - 无残留 PV / VG / LV；
   - loop 设备已释放，无残留；
   - 镜像文件与挂载点目录 `/mnt/lv_test` 已删除。
