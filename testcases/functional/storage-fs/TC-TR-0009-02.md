# TC-TR-0009-02 ｜ LVM 卷管理

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证 LVM 能完成规定的卷管理操作（PV/VG/LV 创建、扩展/缩减、挂载读写）。

## 前置条件

1. RISC-V 平台，已就绪一块或多块可用存储设备。
2. 已安装 lvm2。

## 测试步骤

1. 创建 PV：`pvcreate <设备>`。
2. 创建 VG：`vgcreate <vg名> <设备>`。
3. 创建 LV：`lvcreate -L <大小> -n <lv名> <vg名>`。
4. 在 LV 上创建文件系统并挂载读写。
5. 按支持范围执行卷扩展 `lvextend`（或缩减）。

## 预期结果

1. 步骤 1~3：pvcreate / vgcreate / lvcreate 均成功，退出码为 0。
2. 步骤 4：挂载读写正常。
3. 步骤 5：扩展/缩减操作按支持范围正常完成。
