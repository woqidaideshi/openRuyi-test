# TC-TR-0009-02 ｜ LVM 卷管理

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证 LVM 能完成规定的卷管理操作（PV/VG/LV 创建、扩展/缩减、挂载读写）。

## 前置条件

1. RISC-V 平台，已就绪一块非系统测试盘（如 `/dev/mmcblk0`）。
2. 已安装 lvm2。

## 测试步骤

1. 确认工具与测试盘：
   ```bash
   rpm -q lvm2
   lsblk
   ```
2. 创建 PV / VG / LV：
   ```bash
   sudo pvcreate /dev/mmcblk0
   echo $?
   sudo vgcreate vg_test /dev/mmcblk0
   echo $?
   sudo lvcreate -L 512M -n lv_test vg_test
   echo $?
   ```
3. 在 LV 上创建文件系统并挂载读写：
   ```bash
   sudo mkfs.ext4 /dev/vg_test/lv_test >/dev/null 2>&1
   sudo mkdir -p /mnt/lv_test
   sudo mount /dev/vg_test/lv_test /mnt/lv_test
   echo "lvm-data" | sudo tee /mnt/lv_test/file.txt
   sudo cat /mnt/lv_test/file.txt
   df -h /mnt/lv_test
   ```
4. 扩展 LV 与文件系统并核对数据：
   ```bash
   sudo lvextend -L +512M /dev/vg_test/lv_test
   sudo resize2fs /dev/vg_test/lv_test
   df -h /mnt/lv_test
   sudo cat /mnt/lv_test/file.txt
   ```
5. 清理（卸载、删除 LV/VG/PV）：
   ```bash
   sudo umount /mnt/lv_test
   sudo lvremove -y /dev/vg_test/lv_test
   sudo vgremove -y vg_test
   sudo pvremove -y /dev/mmcblk0
   sudo rmdir /mnt/lv_test
   ```

## 预期结果

1. 步骤 2：pvcreate / vgcreate / lvcreate 均成功，退出码为 0。
2. 步骤 3：LV 上文件系统创建、挂载、读写正常，`file.txt` 内容为 `lvm-data`。
3. 步骤 4：扩展成功，`df -h` 显示容量增加约 512M，原有数据 `lvm-data` 完整可读。
4. 步骤 5：清理完成，无残留 PV/VG/LV。
