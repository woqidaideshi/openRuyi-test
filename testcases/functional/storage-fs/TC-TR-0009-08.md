# TC-TR-0009-08 ｜ CIFS 客户端挂载与授权

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 CIFS(SMB) 客户端能连接受支持服务端，完成挂载、授权读写、只读与错误凭据的边界校验及卸载。服务端与客户端同机部署，通过 `127.0.0.1` 挂载，不依赖外部环境。

## 前置条件

1. RISC-V 平台，已安装 cifs-utils 与 samba。
2. 本机 `445` 端口可用（服务端与客户端同机部署）。

## 测试步骤

1. 准备 SMB 服务端：创建共享目录 `/srv/cifs`，在 `smb.conf` 中加入 `[tc]` 共享段（`writable = yes`、`valid users = tcsmb`），创建 `tcsmb` 账号并设密码，启动 `smb` 服务。
2. 写入凭据文件并挂载共享：
   - 创建权限为 `600` 的凭据文件；
   - 将共享挂载到 `/mnt/cifs`；
   - 执行 `findmnt` 查看挂载类型与协商版本。
3. 执行授权读写校验：先在本地生成源文件并记下 md5，再将它复制到挂载点为 `file.txt`，依次读取以下三处并计算 md5：
   - 挂载点内的 `/mnt/cifs/file.txt`；
   - 共享目录中的 `/srv/cifs/file.txt`；
   - 重新挂载后，挂载点内的 `/mnt/cifs/file.txt`。
4. 卸载后以只读方式重新挂载到 `/mnt/cifs`，尝试向 `/mnt/cifs/ro.txt` 写入内容。
5. 创建空目录 `/mnt/cifs-bad`，用错误密码将同一共享挂载到该目录。
6. 清理：
   - 卸载 `/mnt/cifs`；
   - 删除挂载点目录 `/mnt/cifs` 与空目录 `/mnt/cifs-bad`；
   - 删除凭据文件；
   - 停止 `smb` 服务；
   - 移除 `smb.conf` 中的 `[tc]` 共享段与 `tcsmb` 账号；
   - 删除共享目录 `/srv/cifs`（含测试文件 `file.txt`）。

## 预期结果

1. 步骤 1：`smb` 服务已启动，`smb.conf` 中包含 `[tc]` 共享段。
2. 步骤 2：
   - 凭据文件权限为 `600`；
   - 挂载成功，`findmnt` 显示类型为 `cifs`，未指定 `vers=` 时自动协商到 `vers=3.1.1`；
   - `OPTIONS` 中可见 `username=<账户>`。
3. 步骤 3：
   - 挂载点内的 `/mnt/cifs/file.txt` 与源文件 md5 一致，内容为 `cifs-data`；
   - 共享目录中的 `/srv/cifs/file.txt` 与源文件 md5 一致；
   - 重新挂载后挂载点内的 `/mnt/cifs/file.txt` 仍与源文件 md5 一致。
4. 步骤 4：
   - 只读挂载成功；
   - 向 `/mnt/cifs/ro.txt` 写入失败；
   - 提示 `Read-only file system`。
5. 步骤 5：挂载到 `/mnt/cifs-bad` 失败，提示 `mount error(13): Permission denied`（`/mnt/cifs-bad` 仍为空目录，未产生挂载）。
6. 步骤 6：
   - `/mnt/cifs` 已卸载；
   - 两个目录均已删除；
   - 凭据文件已删除；
   - `smb` 已停止；
   - `[tc]` 共享段与 `tcsmb` 账号已删除；
   - `/srv/cifs` 及其中的 `file.txt` 均已删除。
