# TC-TR-0009-08 ｜ CIFS 客户端挂载与授权

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 CIFS(SMB) 客户端能连接受支持服务端，完成挂载、授权读写、只读与错误凭据的边界校验及卸载。服务端与客户端同机部署，通过 `127.0.0.1` 挂载，不依赖外部环境。

## 前置条件

1. RISC-V 平台，已安装 cifs-utils 与 samba。
2. 本机 `445` 端口可用（服务端与客户端同机部署）。

## 测试步骤

1. 准备 SMB 服务端与共享：
   ```bash
   rpm -q cifs-utils samba
   sudo mkdir -p /srv/cifs
   printf '[tc]\n   path = /srv/cifs\n   writable = yes\n   valid users = tcsmb\n' | sudo tee -a /etc/samba/smb.conf
   sudo useradd -M -s /sbin/nologin tcsmb
   printf 'Tc#2026pass\nTc#2026pass\n' | sudo smbpasswd -s -a tcsmb
   sudo chown tcsmb /srv/cifs
   sudo systemctl start smb
   SERVER=127.0.0.1
   SHARE=tc
   ACCOUNT=tcsmb
   PASSWORD='Tc#2026pass'
   CASE_TMP=/tmp/tc-cifs && rm -rf $CASE_TMP && mkdir -p $CASE_TMP
   ```
2. 写入凭据文件并挂载共享：
   ```bash
   printf 'username=%s\npassword=%s\n' "$ACCOUNT" "$PASSWORD" | sudo tee /etc/tc-cifs.cred
   sudo chmod 600 /etc/tc-cifs.cred; echo "chmod:$?"
   sudo mkdir -p /mnt/cifs
   sudo mount -t cifs "//$SERVER/$SHARE" /mnt/cifs -o credentials=/etc/tc-cifs.cred; echo "mount:$?"
   findmnt -n -o SOURCE,FSTYPE,OPTIONS /mnt/cifs
   ```
3. CIFS 授权读写与 md5 校验：
   ```bash
   echo "cifs-data" > $CASE_TMP/payload.txt
   md5sum $CASE_TMP/payload.txt | awk '{print $1}' > $CASE_TMP/before.md5
   sudo cp $CASE_TMP/payload.txt /mnt/cifs/file.txt
   sudo md5sum /mnt/cifs/file.txt | awk '{print $1}' > $CASE_TMP/after.md5
   diff $CASE_TMP/before.md5 $CASE_TMP/after.md5; echo "md5-diff:$?"
   sudo md5sum /srv/cifs/file.txt | awk '{print $1}' > $CASE_TMP/server.md5
   diff $CASE_TMP/before.md5 $CASE_TMP/server.md5; echo "md5-diff-server:$?"
   sudo cat /mnt/cifs/file.txt
   sudo umount /mnt/cifs
   sudo mount -t cifs "//$SERVER/$SHARE" /mnt/cifs -o credentials=/etc/tc-cifs.cred
   sudo md5sum /mnt/cifs/file.txt | awk '{print $1}' > $CASE_TMP/remount.md5
   diff $CASE_TMP/before.md5 $CASE_TMP/remount.md5; echo "md5-diff-remount:$?"
   sudo rm /mnt/cifs/file.txt
   sudo umount /mnt/cifs; echo "umount:$?"
   ```
   > 三次比对的目的不同：
   > - `md5-diff` 确认写入内容与源一致；
   > - `md5-diff-server` 直接核对共享目录里的文件，证明数据确实落到了对端；
   > - `md5-diff-remount` 在**卸载重挂后**再算一次，排除客户端缓存的影响。
4. 只读挂载后写入：
   ```bash
   sudo mount -t cifs "//$SERVER/$SHARE" /mnt/cifs -o credentials=/etc/tc-cifs.cred,ro; echo "mount:$?"
   echo "ro-data" | sudo tee /mnt/cifs/ro.txt; echo "write:$?"
   sudo umount /mnt/cifs
   ```
5. 错误密码挂载：
   ```bash
   sudo mount -t cifs "//$SERVER/$SHARE" /mnt/cifs -o user="$ACCOUNT",password=wrong; echo "mount:$?"
   ```
6. 清理（删除挂载点与凭据文件，并移除本机服务端）：
   ```bash
   sudo rmdir /mnt/cifs
   sudo rm -f /etc/tc-cifs.cred
   sudo systemctl stop smb
   sudo sed -i '/^\[tc\]$/,+3d' /etc/samba/smb.conf
   sudo userdel tcsmb
   sudo rm -rf /srv/cifs
   rm -rf $CASE_TMP
   ```

## 预期结果

1. 步骤 1：cifs-utils 与 samba 已安装；`smb` 服务已启动，`smb.conf` 中包含 `[tc]` 共享段。
2. 步骤 2：
   - 凭据文件权限为 `600`，`chmod` 退出码为 0；
   - `mount` 退出码为 0；
   - `findmnt` 显示 `FSTYPE` 为 `cifs`，不指定 `vers=` 时自动协商到 `vers=3.1.1`；
   - `OPTIONS` 中可见 `username=<账户>`。
3. 步骤 3：
   - `md5-diff` 退出码为 0（挂载点内文件与源文件一致）；
   - `md5-diff-server` 退出码为 0（共享目录中的文件与源一致）；
   - `md5-diff-remount` 退出码为 0（卸载重挂后仍一致，非客户端缓存）；
   - `umount` 退出码为 0。
4. 步骤 4：
   - 只读挂载成功，`mount` 退出码为 0；
   - 写入失败，`write` 退出码非 0（实测 `1`），提示 `Read-only file system`。
5. 步骤 5：挂载失败，`mount` 退出码非 0（实测 `32`），提示 `mount error(13): Permission denied`。
6. 步骤 6：清理完毕，`smb` 已停止、`[tc]` 共享段与 `tcsmb` 账号已删除、`$CASE_TMP` 已删除、无残留挂载点与凭据文件。
