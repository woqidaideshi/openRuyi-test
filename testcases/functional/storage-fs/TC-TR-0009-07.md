# TC-TR-0009-07 ｜ NFS 客户端挂载与授权

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 NFS 客户端能连接受支持服务端，完成挂载、授权读写、未导出路径拒绝与卸载。服务端与客户端同机部署，通过 `127.0.0.1` 挂载，不依赖外部环境。

## 前置条件

1. RISC-V 平台，已安装 nfs-utils。
2. 本机 `2049` 端口可用（服务端与客户端同机部署）。

## 测试步骤

1. 准备 NFS 服务端与导出：
   ```bash
   rpm -q nfs-utils
   sudo mkdir -p /srv/nfs
   echo '/srv/nfs 127.0.0.1(rw,sync,no_root_squash)' | sudo tee -a /etc/exports
   sudo systemctl start nfs-server
   SERVER=127.0.0.1
   EXPORT=/srv/nfs
   NOEXPORT=/srv/notexported
   CASE_TMP=/tmp/tc-nfs && rm -rf $CASE_TMP && mkdir -p $CASE_TMP
   showmount -e "$SERVER"
   ```
2. 挂载 NFS 共享：
   ```bash
   sudo mkdir -p /mnt/nfs
   sudo mount -t nfs "$SERVER:$EXPORT" /mnt/nfs; echo "mount:$?"
   findmnt -n -o SOURCE,FSTYPE /mnt/nfs
   ```
3. NFS 授权读写与 md5 校验：
   ```bash
   echo "nfs-data" > $CASE_TMP/payload.txt
   md5sum $CASE_TMP/payload.txt | awk '{print $1}' > $CASE_TMP/before.md5
   sudo cp $CASE_TMP/payload.txt /mnt/nfs/file.txt
   sudo md5sum /mnt/nfs/file.txt | awk '{print $1}' > $CASE_TMP/after.md5
   diff $CASE_TMP/before.md5 $CASE_TMP/after.md5; echo "md5-diff:$?"
   sudo md5sum /srv/nfs/file.txt | awk '{print $1}' > $CASE_TMP/server.md5
   diff $CASE_TMP/before.md5 $CASE_TMP/server.md5; echo "md5-diff-server:$?"
   sudo cat /mnt/nfs/file.txt
   sudo umount /mnt/nfs
   sudo mount -t nfs "$SERVER:$EXPORT" /mnt/nfs
   sudo md5sum /mnt/nfs/file.txt | awk '{print $1}' > $CASE_TMP/remount.md5
   diff $CASE_TMP/before.md5 $CASE_TMP/remount.md5; echo "md5-diff-remount:$?"
   sudo rm /mnt/nfs/file.txt
   sudo umount /mnt/nfs; echo "umount:$?"
   ```
   > 三次比对的目的不同：
   > - `md5-diff` 确认写入内容与源一致；
   > - `md5-diff-server` 直接核对服务端导出目录里的文件，证明数据确实落到了对端；
   > - `md5-diff-remount` 在**卸载重挂后**再算一次，排除客户端缓存的影响。
4. NFS 未导出路径挂载：
   ```bash
   sudo mkdir -p /mnt/nfs-bad
   sudo mount -t nfs "$SERVER:$NOEXPORT" /mnt/nfs-bad; echo "mount:$?"
   ```
5. 清理（删除挂载点并移除本机服务端）：
   ```bash
   sudo rmdir /mnt/nfs /mnt/nfs-bad
   sudo systemctl stop nfs-server
   sudo sed -i '\|^/srv/nfs 127.0.0.1|d' /etc/exports
   sudo rm -rf /srv/nfs
   rm -rf $CASE_TMP
   ```

## 预期结果

1. 步骤 1：nfs-utils 已安装；`showmount -e` 列出导出列表，其中包含 `$EXPORT`（实测输出 `/srv/nfs 127.0.0.1`）。
2. 步骤 2：`mount` 退出码为 0，`findmnt` 显示 `FSTYPE` 为 `nfs4`（实测默认协商到 `vers=4.2`；如需 NFSv3，在挂载参数加 `-o vers=3`）。
3. 步骤 3：
   - `md5-diff` 退出码为 0（挂载点内文件与源文件一致）；
   - `md5-diff-server` 退出码为 0（服务端导出目录中的文件与源一致）；
   - `md5-diff-remount` 退出码为 0（卸载重挂后仍一致，非客户端缓存）；
   - `umount` 退出码为 0。
4. 步骤 4：`mount` 退出码非 0（实测 `32`），提示 `access denied by server`（未导出路径被服务端拒绝，授权控制有效）。
5. 步骤 5：清理完毕，`nfs-server` 已停止、`/etc/exports` 中新增的导出行与 `/srv/nfs` 已删除、`$CASE_TMP` 已删除、无残留挂载点。
