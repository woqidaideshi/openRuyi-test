# TC-TR-0009-05 ｜ 升级/迁移数据一致性

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证正式支持的升级/迁移路径下，已持久化文件内容、目录结构及承诺保留的属性保持一致，无数据丢失或损坏。

## 前置条件

1. 已按规定在 `/home`、`/var` 准备持久化测试数据，并记录 md5。
2. 存在受支持的升级/迁移路径与可用升级源。
3. **必须在可一次性占用、允许重启的专用测试机（或虚拟机快照）上执行**；不要在多人共用或验证其他用例的机器上执行 `dnf upgrade`，否则会破坏环境、导致其他用例结论失效。
4. 执行前建议备份关键数据并确认可回滚（如虚拟机快照）。

## 测试步骤

1. 准备持久化测试数据并记录基线：
   ```bash
   mkdir -p /home/openruyi/tc-data
   sudo mkdir -p /var/tc-data
   sudo chown openruyi /var/tc-data
   echo "home-data" > /home/openruyi/tc-data/file.txt
   echo "var-data" > /var/tc-data/file.txt
   find /home/openruyi/tc-data /var/tc-data -type f -exec md5sum {} + | sort -k2 > /tmp/tc-data-before.md5
   ```
2. 执行受支持的升级/迁移路径（如全量升级）：
   ```bash
   sudo dnf upgrade -y
   echo $?
   ```
3. 升级后确认版本：
   ```bash
   uname -a
   head -5 /etc/os-release
   ```
4. 校验持久化数据：
   ```bash
   find /home/openruyi/tc-data /var/tc-data -type f -exec md5sum {} + | sort -k2 > /tmp/tc-data-after.md5
   diff /tmp/tc-data-before.md5 /tmp/tc-data-after.md5
   ```
5. 清理：
   ```bash
   rm -rf /home/openruyi/tc-data
   sudo rm -rf /var/tc-data
   rm -f /tmp/tc-data-before.md5 /tmp/tc-data-after.md5
   ```

## 预期结果

1. 步骤 1：基线数据与 md5 清单生成成功。
2. 步骤 2：升级完成，退出码为 0。
3. 步骤 3：系统正常进入新版本（`/etc/os-release` 版本正确）。
4. 步骤 4：`diff` 无差异，持久化数据内容一致，无数据丢失或损坏。
5. 步骤 5：清理完毕。
