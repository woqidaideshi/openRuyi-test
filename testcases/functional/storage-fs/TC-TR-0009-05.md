# TC-TR-0009-05 ｜ 升级/迁移数据一致性

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证正式支持的升级/迁移路径下，已持久化文件内容、目录结构及承诺保留的属性保持一致，无数据丢失或损坏。

## 前置条件（Setup）

1. 已按规定持久化一组校验文件，并记录内容校验和、目录结构与权限/属主等属性。

## 测试步骤（How to test）

1. 执行受支持的升级/迁移路径。
2. 校验文件内容：对比升级前后的校验和。
3. 校验目录结构与承诺保留的属性（权限、属主、时间戳）。

## 预期结果（Expected Results）

1. 步骤 1：升级/迁移完成。
2. 步骤 2：文件内容校验一致（校验和相同）。
3. 步骤 3：目录结构与属性保持正确，无数据丢失或损坏。
