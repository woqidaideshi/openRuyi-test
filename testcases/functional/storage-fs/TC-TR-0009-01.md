# TC-TR-0009-01 ｜ ext4/xfs 创建挂载修复

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证 ext4/XFS 能正常创建、挂载、读写、卸载，并在规定的可修复故障场景下完成检查与修复。

## 前置条件（Setup）

1. RISC-V 平台，已就绪可用的存储设备（分区或回环设备）。
2. 已安装 e2fsprogs / xfsprogs。

## 测试步骤（How to test）

1. 创建 ext4 文件系统：`mkfs.ext4 <设备>`；创建 XFS 文件系统：`mkfs.xfs <设备>`。
2. 挂载：`mkdir -p /mnt/ext4 /mnt/xfs`，`mount <设备> /mnt/ext4`，`mount <设备> /mnt/xfs`。
3. 读写校验：在挂载点写入文件并读回，对比校验和。
4. 卸载：`umount /mnt/ext4`、`umount /mnt/xfs`。
5. 可修复故障场景：`fsck.ext4 -f <设备>` / `xfs_repair <设备>`，完成检查与修复。

## 预期结果（Expected Results）

1. 步骤 1：mkfs 创建成功，退出码为 0。
2. 步骤 2：挂载成功，挂载点可访问。
3. 步骤 3：写入/读回内容一致。
4. 步骤 4：卸载成功。
5. 步骤 5：fsck / xfs_repair 完成检查与修复，无未修复错误。
