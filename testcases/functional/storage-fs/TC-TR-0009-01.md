# TC-TR-0009-01 ｜ ext4/xfs 创建挂载修复

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0009（存储与文件系统功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 存储与文件系统 |
| 优先级 | P1 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证 ext4/XFS 能正常创建、挂载、读写、卸载，并在规定的可修复故障场景下完成检查与修复。

## 前置条件

1. RISC-V 平台，已就绪一块非系统测试盘（如 `/dev/mmcblk0`），已用 `lsblk` 确认非系统盘。
2. 已安装 e2fsprogs、xfsprogs。

## 测试步骤

1. 确认工具与测试盘状态：
   ```bash
   rpm -q e2fsprogs xfsprogs
   lsblk
   ```
2. 创建 ext4 文件系统：
   ```bash
   sudo mkfs.ext4 -F /dev/mmcblk0
   echo $?
   ```
3. 挂载并读写校验：
   ```bash
   sudo mkdir -p /mnt/ext4
   sudo mount /dev/mmcblk0 /mnt/ext4
   echo "ext4-data" | sudo tee /mnt/ext4/file.txt
   md5sum /mnt/ext4/file.txt
   sudo cat /mnt/ext4/file.txt
   sudo umount /mnt/ext4
   ```
4. 重新挂载校验数据持久化：
   ```bash
   sudo mount /dev/mmcblk0 /mnt/ext4
   sudo cat /mnt/ext4/file.txt
   sudo umount /mnt/ext4
   ```
5. ext4 检查：
   ```bash
   sudo e2fsck -fn /dev/mmcblk0
   echo $?
   ```
6. 创建 XFS 文件系统并挂载读写：
   ```bash
   sudo mkfs.xfs -f /dev/mmcblk0
   echo $?
   sudo mkdir -p /mnt/xfs
   sudo mount /dev/mmcblk0 /mnt/xfs
   echo "xfs-data" | sudo tee /mnt/xfs/file.txt
   sudo cat /mnt/xfs/file.txt
   sudo umount /mnt/xfs
   ```
7. XFS 检查：
   ```bash
   sudo xfs_repair -n /dev/mmcblk0
   echo $?
   ```
8. 清理挂载点：
   ```bash
   sudo rmdir /mnt/ext4 /mnt/xfs
   ```

## 预期结果

1. 步骤 1：两个工具包已安装，测试盘存在且非系统盘。
2. 步骤 2：mkfs.ext4 创建成功，退出码为 0。
3. 步骤 3：挂载成功，写入读回内容一致。
4. 步骤 4：重新挂载后 `file.txt` 内容仍为 `ext4-data`。
5. 步骤 5：e2fsck 检查完成，无未修复错误。
6. 步骤 6：mkfs.xfs 创建成功，挂载读写正常。
7. 步骤 7：xfs_repair 检查通过，退出码为 0。
8. 步骤 8：清理完毕。
