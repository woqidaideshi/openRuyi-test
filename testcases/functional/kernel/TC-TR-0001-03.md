# TC-TR-0001-03 ｜ 触发内核保留上限清理时最旧运行内核保留

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0001（内核更新不会移除当前使用的内核以及模块） |
| 测试类型 | 功能测试 |
| 功能模块 | 内核与引导 |
| 优先级 | P2 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证触发内核版本保留上限清理时，运行中的最旧内核及其模块不被移除，重启后仍可正常引导。

## 前置条件（Setup）

1. 已安装多个内核版本，接近产品默认的内核保留上限。
2. 当前运行内核为已安装的最旧版本。
3. 已记录当前运行内核版本：`uname -r`。

## 测试步骤（How to test）

1. 确认当前运行内核为已安装最旧版本：对比 `uname -r` 与 `rpm -qa 'kernel*'`。
2. 执行 `dnf update`，触发内核保留上限清理。
3. 核对运行中内核未被移除：
   - `rpm -q kernel-<旧版本>`
   - `/boot/vmlinuz-<旧版本>`
   - `/boot/initramfs-<旧版本>.img`
   - `/usr/lib/modules/<旧版本>`
4. 重启系统并确认可正常引导。

## 预期结果（Expected Results）

1. 步骤 1：确认当前运行内核为已安装最旧版本。
2. 步骤 2：更新完成并触发保留上限清理。
3. 步骤 3：运行中内核包、映像、模块完整保留。
4. 步骤 4：重启可正常引导，无错误提示。
