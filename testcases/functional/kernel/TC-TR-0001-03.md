# TC-TR-0001-03 ｜ 触发内核保留上限清理时最旧运行内核保留

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0001（内核更新不会移除当前使用的内核以及模块） |
| 测试类型 | 功能测试 |
| 功能模块 | 内核与引导 |
| 优先级 | P2 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证触发内核保留上限清理时，运行中的最旧内核不被移除且重启仍可引导。

## 前置条件

多内核版本接近保留上限，当前运行内核为已安装最旧版本

## 测试步骤

1. 确认当前运行内核为已安装最旧版本
2. 执行更新/清理触发保留上限机制
3. 核对运行中内核包与 /boot 映像未被移除
4. 重启后仍可引导

## 预期结果

1. 清理触发后运行中的内核包、映像、模块完整保留
2. 重启可正常引导
3. 无错误提示
