# TC-TR-001-01 ｜ 内核更新后原内核保留、系统持续可用

| 字段 | 值 |
|---|---|
| 关联需求 | TR-001（内核更新不会移除当前使用的内核以及模块） |
| 需求域 | 内核与引导 |
| 优先级/门禁 | P2 |
| 自动化等级（执行方式） | 半自动 |
| 适用平台/发布件 | rva20/rva23 · 安装/镜像产物 |
| 相关软件包 | linux |
| 实现脚本路径 | tests/functional/kernel/boot/ |
| 状态 | 草稿 |
| 备注 | 对应验收子项①；保留上限依赖默认配置（D5 待确认） |

## 描述

验证内核更新后原内核软件包、映像及配套模块完整保留，未重启时系统继续运行原内核且关键功能正常。

## 前置条件

联网可达 dnf 仓库；/boot 空间充足；记录更新前 uname -r 与 rpm -qa 'kernel*'

## 测试步骤

1. 记录更新前内核版本与已装内核包
2. 执行 dnf update 完成内核更新
3. 不重启，核对原内核 rpm、/boot/vmlinuz-原、initramfs-原、/usr/lib/modules/原均存在
4. 核对引导器配置中原内核引导项仍存在
5. 验证原内核关键功能正常，适用的未加载模块 modprobe 加载成功

## 预期结果

1. 更新前运行内核的软件包、映像、模块完整保留
2. 未重启时系统继续运行原内核且关键功能正常
3. 原内核引导项仍存在
4. 失败时 dnf/内核日志有明确错误
