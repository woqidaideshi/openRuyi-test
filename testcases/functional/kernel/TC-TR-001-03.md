# TC-TR-001-03 ｜ 触发内核保留上限清理时最旧运行内核保留

| 字段 | 值 |
|---|---|
| 关联需求 | TR-001（内核更新不会移除当前使用的内核以及模块） |
| 需求域 | 内核与引导 |
| 优先级/门禁 | P2 |
| 自动化等级（执行方式） | 半自动 |
| 适用平台/发布件 | rva20/rva23 · 安装/镜像产物 |
| 相关软件包 | linux |
| 实现脚本路径 | tests/functional/kernel/boot/ |
| 状态 | 草稿 |
| 备注 | 对应验收子项③；保留数量与清理规则待明确 |

## 描述

验证触发内核保留上限清理时，运行中的最旧内核不被移除且重启仍可引导。

## 前置条件

多内核版本接近保留上限，当前运行内核为已安装最旧版本

## 测试步骤

1. 确认当前运行内核为已安装最旧版本
2. 执行更新/清理触发保留上限机制
3. 核对运行中内核包与 /boot 映像未被移除
4. 重启后仍可引导

## 预期结果

1. 清理触发后运行中的内核包、映像、模块完整保留
2. 重启可正常引导
3. 无错误提示
