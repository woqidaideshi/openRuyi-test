# TC-TR-0001-02 ｜ 使用旧内核重启后功能正常

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0001（内核更新不会移除当前使用的内核以及模块） |
| 测试类型 | 功能测试 |
| 功能模块 | 内核与引导 |
| 优先级 | P2 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证内核更新后重启时，引导菜单中旧内核引导项仍存在，选择旧内核可正常启动，登录后运行内核为旧内核且关键功能正常。

## 前置条件

1. 已完成内核更新且系统未重启，当前运行内核仍为旧内核。

## 测试步骤

1. 记录当前运行内核版本 `uname -r`，记作 `<version>`。
2. 重启系统，在引导菜单中查看 `<version>` 的引导项。
3. 选择 `<version>` 引导项启动，登录后查看运行内核版本 `uname -r`。
4. 加载与卸载内核模块：加载内核模块 `dummy` 后查看内核模块列表，再卸载该模块后再次查看内核模块列表。

## 预期结果

1. 步骤 1：得到当前旧内核版本号。
2. 步骤 2：系统重启后进入引导菜单，菜单中存在旧内核（`<version>`）引导项。
3. 步骤 3：旧内核成功启动并可登录，`uname -r` 输出为 `<version>`。
4. 步骤 4：加载后内核模块列表中包含 `dummy`，卸载后列表不再包含 `dummy`。
