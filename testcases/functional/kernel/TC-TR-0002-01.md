# TC-TR-0002-01 ｜ 内核更新后新内核安装完整、引导项生成

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0002（内核更新后增加对应引导项） |
| 测试类型 | 功能测试 |
| 功能模块 | 内核与引导 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证内核更新后新内核软件包、映像及配套模块安装完整，并生成对应引导项。

## 前置条件

联网可达 dnf 仓库；默认配置

## 测试步骤

1. 执行 dnf update（含内核更新）
2. 核对新内核 rpm、/boot/vmlinuz-新、initramfs-新、/usr/lib/modules/新均存在
3. 核对引导器配置（grub.cfg / BLS entry）中已生成新内核引导项

## 预期结果

1. 新内核软件包、映像、模块安装完整
2. 引导器配置中生成新内核引导项
