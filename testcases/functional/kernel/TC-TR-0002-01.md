# TC-TR-0002-01 ｜ 内核更新后新内核安装完整、引导项生成

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0002（内核更新后增加对应引导项） |
| 测试类型 | 功能测试 |
| 功能模块 | 内核与引导 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证内核更新后，新内核软件包、映像及配套模块安装完整，并在引导器配置中生成对应引导项。

## 前置条件（Setup）

1. 系统使用产品默认配置。
2. 网络可达 dnf 仓库。
3. 已记录更新前内核版本：`uname -r`。

## 测试步骤（How to test）

1. 执行 `dnf update`（含内核更新），记录新内核版本。
2. 核对新内核 rpm 包已安装：`rpm -q kernel-<新版本>`。
3. 核对新内核映像与模块存在：
   - `/boot/vmlinuz-<新版本>`
   - `/boot/initramfs-<新版本>.img`
   - `/usr/lib/modules/<新版本>`
4. 核对引导器配置（`/boot/grub2/grub.cfg` 或 `/boot/loader/entries/*.conf`）中已生成新内核引导项。

## 预期结果（Expected Results）

1. 步骤 1：`dnf update` 完成，新内核安装成功。
2. 步骤 2：新内核 rpm 包已安装。
3. 步骤 3：新内核 vmlinuz、initramfs、模块目录均存在。
4. 步骤 4：引导器配置中已生成新内核引导项。
