# TC-TR-0002-01 ｜ 内核更新后新内核安装完整、引导项生成

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0002（内核更新后增加对应引导项） |
| 测试类型 | 功能测试 |
| 功能模块 | 内核与引导 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证更新内核后，新内核软件包、映像、配套模块及引导项安装完整。

## 前置条件

1. 已安装产品默认配置的 Linux 内核，且当前运行内核非最新版本。
2. 网络可达 dnf 仓库。
3. `/boot` 分区空间充足，可容纳新增内核。

## 测试步骤

1. 查看可升级的内核版本，记作 `<新版本>`：
   ```bash
   dnf check-update linux 2>/dev/null | grep '^linux\.' | awk '{print $2}'
   ```
2. 执行内核更新：`dnf update linux`，等待完成。
3. 查看更新后的最新内核版本，记作 `<version>`：
   ```bash
   rpm -q --qf '%{version}-%{release}\n' linux | sort -V | tail -1
   ```
4. 查看新内核相关包列表：
   ```bash
   rpm -qa | grep linux | grep "<version>"
   ```
5. 查看新内核映像文件（EFI 目录下的 `linux` 与 `initrd`）：
   ```bash
   find /boot/ -type d -name "<version>" -print -exec ls -la {} \;
   ```
6. 查看新内核模块：
   ```bash
   find /usr/lib/modules/<version> -name '*.ko*' | head
   ```
7. 查看引导器配置中的新内核引导项：
   ```bash
   find /boot/efi/loader/entries/ -name "*<version>.conf"
   ```

## 预期结果

1. 步骤 1：输出可升级的内核版本 `<新版本>`。
2. 步骤 2：更新完成，退出码为 0。
3. 步骤 3：`<version>` 等于步骤 1 的 `<新版本>`。
4. 步骤 4：新内核相关包（linux、linux-core、linux-modules、linux-dtbs）均已安装。
5. 步骤 5：`<version>` 目录存在，且含 `linux`、`initrd` 两个文件。
6. 步骤 6：`/usr/lib/modules/<version>` 下存在 `.ko*` 模块文件（非空）。
7. 步骤 7：存在匹配 `*<version>.conf` 的引导项。
