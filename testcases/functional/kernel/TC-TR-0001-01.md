# TC-TR-0001-01 ｜ 内核更新后原内核保留、系统持续可用

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0001（内核更新不会移除当前使用的内核以及模块） |
| 测试类型 | 功能测试 |
| 功能模块 | 内核与引导 |
| 优先级 | P2 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证内核更新后原内核软件包、映像及配套模块完整保留，未重启时系统继续运行原内核且关键功能正常。

## 前置条件

联网可达 dnf 仓库；/boot 空间充足；记录更新前uname  -r 与 rpm -qa 'kernel*'

## 测试步骤

1. 记录更新前内核版本、已装内核包记忆内核包的所有文件
2. 执行 `dnf update linux` 完成内核更新
3. 不重启，核对原内核 rpm、/boot/vmlinuz-原、initramfs-原、/usr/lib/modules/原均存在
4. 核对引导器配置中原内核引导项仍存在
5. 验证原内核关键功能正常，适用的未加载模块 modprobe 加载成功

## 预期结果

1. 更新前运行内核的软件包、映像、模块完整保留
2. 未重启时系统继续运行原内核且关键功能正常
3. 原内核引导项仍存在
4. 失败时 dnf/内核日志有明确错误
