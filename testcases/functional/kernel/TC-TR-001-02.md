# TC-TR-001-02 ｜ 使用旧内核重启后功能正常

| 字段 | 值 |
|---|---|
| 关联需求 | TR-001（内核更新不会移除当前使用的内核以及模块） |
| 需求域 | 内核与引导 |
| 优先级/门禁 | P2 |
| 自动化等级（执行方式） | 半自动 |
| 适用平台/发布件 | rva20/rva23 · 安装/镜像产物 |
| 相关软件包 | linux |
| 实现脚本路径 | tests/functional/kernel/boot/ |
| 状态 | 草稿 |
| 备注 | 对应验收子项② |

## 描述

验证内核更新后重启，引导菜单中旧内核引导项仍存在，选择旧内核可正常启动且功能正常。

## 前置条件

已完成内核更新（新内核已安装）；更新前运行的内核为旧内核

## 测试步骤

1. 重启系统进入引导菜单
2. 检查旧内核引导项仍存在
3. 选择旧内核引导项启动
4. 登录后执行基础命令，验证关键功能正常

## 预期结果

1. 引导菜单中旧内核引导项仍可见
2. 旧内核成功启动
3. 系统功能正常
