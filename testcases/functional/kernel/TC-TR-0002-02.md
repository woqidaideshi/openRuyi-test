# TC-TR-0002-02 ｜ 使用新内核重启后功能正常

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0002（内核更新后增加对应引导项） |
| 测试类型 | 功能测试 |
| 功能模块 | 内核与引导 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证内核更新后重启时，引导菜单中出现新内核引导项，选择新内核可正常启动，登录后运行内核为新内核且关键功能正常。

## 前置条件

1. 已完成内核更新，新内核已安装且系统未重启，当前运行内核仍为旧内核。

## 测试步骤

1. 记录新内核版本号，记作 `<version>`：
   ```bash
   rpm -q --qf '%{version}-%{release}\n' linux | sort -V | tail -1
   ```
2. 重启系统：`sudo reboot`。
3. 进入引导菜单，查看其中的新内核引导项。
4. 选择新内核（`<version>`）引导项启动。
5. 登录系统，查看当前运行内核版本：`uname -r`。
6. 验证关键功能（加载一个未加载的内核模块）：
   1. 加载 kvm 模块：`sudo modprobe kvm`
   2. 查看 kvm 模块加载状态：`lsmod | grep kvm`

## 预期结果

1. 步骤 2：系统重启并进入引导菜单。
2. 步骤 3：引导菜单中存在新内核（`<version>`）引导项。
3. 步骤 4：新内核成功启动并进入系统。
4. 步骤 5：`uname -r` 输出为 `<version>`（新内核版本）。
5. 步骤 6：
   1. `sudo modprobe kvm` 无报错（退出码为 0）。
   2. `lsmod | grep kvm` 非空。
