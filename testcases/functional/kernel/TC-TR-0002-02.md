# TC-TR-0002-02 ｜ 使用新内核重启后功能正常

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0002（内核更新后增加对应引导项） |
| 测试类型 | 功能测试 |
| 功能模块 | 内核与引导 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证内核更新后重启时，引导菜单出现新版本内核引导项，选择新内核可成功启动且关键功能正常。

## 前置条件（Setup）

1. 已完成内核更新，新内核已安装。
2. 已记录新内核版本号。

## 测试步骤（How to test）

1. 重启系统进入引导菜单：`reboot`。
2. 检查引导菜单中新版本内核引导项是否出现。
3. 选择新内核引导项启动。
4. 登录后验证关键功能正常：`uname -r` 输出为新内核版本。

## 预期结果（Expected Results）

1. 步骤 2：引导菜单中可见新版本内核引导项。
2. 步骤 3：新内核成功启动并进入系统。
3. 步骤 4：`uname -r` 为新内核版本，关键功能正常。
