# TC-TR-0002-02 ｜ 使用新内核重启后功能正常

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0002（内核更新后增加对应引导项） |
| 测试类型 | 功能测试 |
| 功能模块 | 内核与引导 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证内核更新后重启，引导菜单出现新版本内核引导项，选择新内核可成功启动且功能正常。

## 前置条件

已完成内核更新（新内核已安装）

## 测试步骤

1. 重启系统进入引导菜单
2. 检查新版本内核引导项
3. 选择新内核引导项启动
4. 登录后执行基础命令，验证关键功能正常

## 预期结果

1. 引导菜单可见新版本内核引导项
2. 新内核成功启动
3. 系统功能正常
