# TC-TR-002-01 ｜ 内核更新后新内核安装完整、引导项生成

| 字段 | 值 |
|---|---|
| 关联需求 | TR-002（内核更新后增加对应引导项） |
| 需求域 | 内核与引导 |
| 优先级/门禁 | P1 |
| 自动化等级（执行方式） | 半自动 |
| 适用平台/发布件 | rva20/rva23 · 安装/镜像产物 |
| 相关软件包 | linux |
| 实现脚本路径 | tests/functional/kernel/boot/ |
| 状态 | 草稿 |
| 备注 | 对应验收子项① |

## 描述

验证内核更新后新内核软件包、映像及配套模块安装完整，并生成对应引导项。

## 前置条件

联网可达 dnf 仓库；默认配置

## 测试步骤

1. 执行 dnf update（含内核更新）
2. 核对新内核 rpm、/boot/vmlinuz-新、initramfs-新、/usr/lib/modules/新均存在
3. 核对引导器配置（grub.cfg / BLS entry）中已生成新内核引导项

## 预期结果

1. 新内核软件包、映像、模块安装完整
2. 引导器配置中生成新内核引导项
