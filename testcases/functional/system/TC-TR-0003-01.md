# TC-TR-0003-01 ｜ systemd 服务启停/禁用

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0003（服务正常启动停止/禁用） |
| 测试类型 | 功能测试 |
| 功能模块 | 系统服务与管理 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 `systemctl start / stop / enable / disable` 能正确管理服务生命周期，服务状态与命令一致。

## 前置条件

1. 系统使用 systemd 作为 init。
2. 创建测试服务并重载 systemd：
   ```bash
   sudo tee /etc/systemd/system/ruyi-test.service > /dev/null <<'EOF'
   [Unit]
   Description=Test service for ruyi-test

   [Service]
   Type=simple
   ExecStart=/usr/bin/sleep infinity

   [Install]
   WantedBy=multi-user.target
   EOF
   sudo systemctl daemon-reload
   ```

## 测试步骤

1. 启动服务并查看状态：
   ```bash
   sudo systemctl start ruyi-test
   systemctl is-active ruyi-test
   ```
2. 停止服务并查看状态：
   ```bash
   sudo systemctl stop ruyi-test
   systemctl is-active ruyi-test
   ```
3. 设置开机自启并查看状态：
   ```bash
   sudo systemctl enable ruyi-test
   systemctl is-enabled ruyi-test
   ```
4. 取消开机自启并查看状态：
   ```bash
   sudo systemctl disable ruyi-test
   systemctl is-enabled ruyi-test
   ```
5. 清理测试服务：
   ```bash
   sudo rm -f /etc/systemd/system/ruyi-test.service
   sudo systemctl daemon-reload
   systemctl is-enabled ruyi-test
   ```

## 预期结果

1. 步骤 1：`systemctl start` 退出码为 0，`systemctl is-active` 输出 `active`。
2. 步骤 2：`systemctl stop` 退出码为 0，`systemctl is-active` 输出 `inactive`。
3. 步骤 3：`systemctl enable` 退出码为 0，`systemctl is-enabled` 输出 `enabled`。
4. 步骤 4：`systemctl disable` 退出码为 0，`systemctl is-enabled` 输出 `disabled`。
5. 步骤 5：测试服务文件已删除，`daemon-reload` 后 `systemctl is-enabled` 输出 `not-found`（退出码 `4`）。
