# TC-TR-0003-01 ｜ systemd 服务启停/禁用

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0003（服务正常启动停止/禁用） |
| 测试类型 | 功能测试 |
| 功能模块 | 系统服务与管理 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 `systemctl start / stop / enable / disable` 能正确管理服务生命周期，服务状态与命令一致。

## 前置条件

1. 系统使用 systemd 作为 init。
2. 已创建测试服务单元 `/etc/systemd/system/ruyi-test.service`（`Type=simple`，`ExecStart=/usr/bin/sleep infinity`），并执行 `systemctl daemon-reload`。

## 测试步骤

1. 启动 `ruyi-test.service`，查看运行状态。
2. 停止 `ruyi-test.service`，查看运行状态。
3. 启用 `ruyi-test.service` 的开机自启，查看自启状态。
4. 禁用 `ruyi-test.service` 的开机自启，查看自启状态。
5. 清理：
   - 删除测试服务单元；
   - 执行 `systemctl daemon-reload`；
   - 查看 `ruyi-test.service` 的自启状态。

## 预期结果

1. 步骤 1：启动后运行状态为 `active`。
2. 步骤 2：停止后运行状态为 `inactive`。
3. 步骤 3：启用后自启状态为 `enabled`。
4. 步骤 4：禁用后自启状态为 `disabled`。
5. 步骤 5：
   - 单元文件已删除；
   - `daemon-reload` 无报错；
   - `ruyi-test.service` 已查不到（自启状态查询提示未找到该单元）。
