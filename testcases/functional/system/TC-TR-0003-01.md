# TC-TR-0003-01 ｜ systemd 服务启停/禁用

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0003（服务正常启动停止/禁用） |
| 测试类型 | 功能测试 |
| 功能模块 | 系统服务与管理 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 `systemctl start / stop / enable / disable` 能正确管理服务生命周期，服务状态与命令一致。

## 前置条件（Setup）

1. 系统使用 systemd 作为 init。
2. 选定一个未在运行的测试服务（如 `chronyd`，或自建 unit）。

## 测试步骤（How to test）

1. 启动服务：`systemctl start <服务>`。
2. 确认服务已启动：`systemctl is-active <服务>`。
3. 停止服务：`systemctl stop <服务>`。
4. 确认服务已停止：`systemctl is-active <服务>`。
5. 设置开机自启：`systemctl enable <服务>`，`systemctl is-enabled <服务>`。
6. 取消开机自启：`systemctl disable <服务>`，`systemctl is-enabled <服务>`。

## 预期结果（Expected Results）

1. 步骤 1/3/5/6 命令退出码均为 0。
2. 步骤 2：`systemctl is-active` 输出 `active`。
3. 步骤 4：`systemctl is-active` 输出 `inactive`。
4. 步骤 5：`systemctl is-enabled` 输出 `enabled`。
5. 步骤 6：`systemctl is-enabled` 输出 `disabled`。
