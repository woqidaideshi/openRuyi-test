# TC-TR-0007-01 ｜ root 修改 hostname

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0007（root 用户可以修改 hostname） |
| 测试类型 | 功能测试 |
| 功能模块 | 系统服务与管理 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 `hostname` / `hostnamectl` 显示与 `/etc/hostname` 一致，修改后 `/etc/hostname` 相应更新。

## 前置条件（Setup）

1. 使用 root 账户登录。

## 测试步骤（How to test）

1. 查看当前主机名：`hostname` 与 `hostnamectl`。
2. 核对主机名配置文件：`cat /etc/hostname`。
3. 修改主机名：`hostnamectl set-hostname <新主机名>`。
4. 再次核对：`cat /etc/hostname`。

## 预期结果（Expected Results）

1. 步骤 1/2：`hostname`、`hostnamectl` 显示与 `/etc/hostname` 内容一致。
2. 步骤 3：修改命令退出码为 0。
3. 步骤 4：`/etc/hostname` 内容已更新为新主机名。
