# TC-TR-0005-01 ｜ 时间同步正常

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0005（时间同步正常） |

| 功能模块 | 系统服务与管理 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证系统启动后 timesyncd/chrony 服务默认启动，且系统时钟同步正常。

## 前置条件

1. 网络已连接。
2. 已安装时间同步软件（systemd-timesyncd 或 chrony）。

## 测试步骤

1. 确定默认启动的时间同步服务：
   ```bash
   systemctl list-unit-files --type=service --state=enabled | grep -E 'chronyd|systemd-timesyncd'
   ```
   输出为 `enabled` 的服务即默认启动的时间同步服务。

2. 查看服务状态
   - systemd-timesyncd：
     ```bash
     systemctl is-active systemd-timesyncd
     systemctl is-enabled systemd-timesyncd
     ```
   - chrony
     ```bash
     systemctl is-active chronyd
     systemctl is-enabled chronyd
     ```
3. 查看同步
   - systemd-timesyncd：
     ```bash
     timedatectl show -p NTPSynchronized
     ```
   - chrony
     ```bash
     chronyc tracking
     ```

## 预期结果

1. 步骤 1：chronyd 与 systemd-timesyncd 中只有一个为 `enabled`。
2. 步骤 2：只有一个服务为 `active`，另一个为 `inactive`。
3. 步骤 3（按分支）：
   - systemd-timesyncd：`timedatectl show -p NTPSynchronized` 输出 `NTPSynchronized=yes`。
   - chrony：`chronyc tracking` 显示 `Leap status: Normal`。
