# TC-TR-0004-01 ｜ 基本关机与重启

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0004（基本关机重启） |
| 测试类型 | 功能测试 |
| 功能模块 | 系统服务与管理 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证在虚拟控制台以 root 执行 `reboot` 后系统正常重启，重启后非 root 账户可登录，再执行 `shutdown` 后系统正常关机。

## 前置条件

1. 发布件形态具备关机/重启条件（非 oci 发布件）。
2. 可通过本地控制台登录（物理机显示器键盘，或虚拟机 console）。
3. 已存在具备 sudo 权限的非 root 账户（如 `openruyi`）；若没有，测试前先以 root 创建并授予 sudo 权限。

## 测试步骤

1. 切换到虚拟控制台（物理机 `Ctrl+Alt+F3`，或虚拟机 console），以 root 账户登录。
2. 执行重启：`reboot`。
3. 等待系统重启完成，进入登录界面。
4. 使用非 root 账户（如 `openruyi`）登录。
5. 执行关机：`sudo shutdown -h now`。

## 预期结果

1. 步骤 1：成功进入虚拟控制台并完成 root 登录（出现 shell 提示符）。
2. 步骤 2：系统正常重启并进入登录界面。
3. 步骤 4：非 root 账户登录成功。
4. 步骤 5：系统正常关机。
