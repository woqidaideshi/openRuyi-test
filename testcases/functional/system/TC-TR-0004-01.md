# TC-TR-0004-01 ｜ 基本关机与重启

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0004（基本关机重启） |
| 测试类型 | 功能测试 |
| 功能模块 | 系统服务与管理 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证 reboot 重启与 shutdown 关机正常，重启后非 root 账户可登录。

## 前置条件

具备关机/重启条件，虚拟控制台可登录

## 测试步骤

1. 切换到虚拟控制台，root 登录
2. 执行 reboot
3. 等待系统重启完成
4. 使用非 root 账户登录（无则先创建）
5. 执行 shutdown 关机

## 预期结果

1. 系统正常重启并进入登录界面
2. 非 root 账户可登录
3. shutdown 后系统正常关机
