# TC-TR-0004-01 ｜ 基本关机与重启

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0004（基本关机重启） |
| 测试类型 | 功能测试 |
| 功能模块 | 系统服务与管理 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证在虚拟控制台以 root 分别通过兼容命令（`reboot`、`poweroff`、`shutdown -h now`）与 systemctl 入口（`systemctl reboot`、`systemctl poweroff`）执行重启/关机时，系统均能正常完成，且重启或重新开机后非 root 账户可登录。

## 前置条件

1. 发布件形态具备关机/重启条件（非 oci 发布件）。
2. 可通过本地控制台登录（物理机显示器键盘，或虚拟机 console）。
3. 已存在具备 sudo 权限的非 root 账户（如 `openruyi`）。
4. 测试期间能够重新开机（如虚拟机执行 `virsh start <域>`、物理机手动按下电源键）。

## 测试步骤

1. 确认入口与基线：
    - 确认 init 为 systemd：`ps -p 1 -o comm=`
    - 查看兼容命令的指向：`ls -l /usr/sbin/reboot /usr/sbin/poweroff /usr/sbin/shutdown`
    - 记录当前启动标识：`cat /proc/sys/kernel/random/boot_id`
    - 切到虚拟控制台（物理机 `Ctrl+Alt+F3`，虚拟机 console），以 root 登录
2. 执行 `reboot` 重启，待系统回到登录界面后复核：
    - 用非 root 账户登录并执行 `whoami`
    - 系统运行状态：`systemctl is-system-running`
    - 关机流程标记是否存在：`ls /run/nologin`
    - 启动标识：`cat /proc/sys/kernel/random/boot_id`
3. 执行 `systemctl reboot` 重启，按步骤 2 的四项复核。
4. 执行 `shutdown -h now` 关机，确认系统已关闭；重新开机登录后按步骤 2 的四项复核。
5. 执行 `poweroff` 关机，同上复核。
6. 执行 `systemctl poweroff` 关机，同上复核。

## 预期结果

1. 步骤 1：init 为 `systemd`；`reboot`/`poweroff`/`shutdown` 均为指向 `systemctl` 的兼容入口；启动标识已记录；root 控制台登录成功并出现 shell 提示符。
2. 步骤 2：`reboot` 后系统完成重启并回到登录界面，无卡死或异常报错；
    - 非 root 账户登录成功，`whoami` 输出该账户名；
    - `is-system-running` 输出 `running`（不是 `degraded`/`starting`）；
    - `/run/nologin` 不存在；
    - 启动标识与上一次记录值不同。
3. 步骤 3：`systemctl reboot` 后果与步骤 2 一致。
4. 步骤 4：`shutdown -h now` 后系统正常关闭（无卡死）；重新开机登录后，步骤 2 的后四项均满足。
5. 步骤 5：`poweroff` 后结果与步骤 4 一致。
6. 步骤 6：`systemctl poweroff` 后结果与步骤 4 一致。
