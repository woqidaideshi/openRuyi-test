# TC-TR-0004-01 ｜ 基本关机与重启

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0004（基本关机重启） |
| 测试类型 | 功能测试 |
| 功能模块 | 系统服务与管理 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证 `reboot` 能正常重启、`shutdown` 能正常关机，重启后非 root 账户可登录。

## 前置条件（Setup）

1. 发布件形态具备关机/重启条件（非 oci 发布件）。
2. 已存在一个非 root 账户（如 `openruyi`），或可在 root 下创建。

## 测试步骤（How to test）

1. 切换到虚拟控制台，使用 root 账户登录。
2. 执行重启：`reboot`。
3. 等待系统重启完成，进入登录界面。
4. 使用非 root 账户（如 `openruyi`）登录。
5. 登录后执行关机：`shutdown -h now`。

## 预期结果（Expected Results）

1. 步骤 2：系统正常重启并进入登录界面。
2. 步骤 4：非 root 账户可成功登录。
3. 步骤 5：系统正常关机。
