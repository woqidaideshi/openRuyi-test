# TC-TR-0006-01 ｜ 系统日志正常收集

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0006（系统日志正常收集） |
| 测试类型 | 功能测试 |
| 功能模块 | 系统服务与管理 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证系统日志能被正常收集，日志不为空，且最新条目与当前时间相符。

## 前置条件

1. 系统已启动。
2. 已安装日志收集服务（systemd-journald 或 rsyslog）。

## 测试步骤

1. 用 `systemctl is-active` 查看 `systemd-journald` 与 `rsyslog` 的运行状态。
2. 查看本次启动以来的日志：
   - 使用 `systemd-journald`：执行 `journalctl -aeb`；
   - 使用 `rsyslog`：查看 `/var/log/auth`（日志文件路径由 `/etc/rsyslog.conf` 决定）。
3. 记录最新日志条目的时间戳，与当前系统时间对照。

## 预期结果

1. 步骤 1：`systemctl is-active` 显示两者中至少一个为 `active`。
2. 步骤 2：
   - `systemd-journald` 分支：`journalctl -aeb` 有输出，内容非空；
   - `rsyslog` 分支：`/var/log/auth` 有输出，内容非空。
3. 步骤 3：最新条目时间与当前系统时间相符（时差在分钟级以内）。
