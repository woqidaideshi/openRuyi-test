# TC-TR-0006-01 ｜ 系统日志正常收集

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0006（系统日志正常收集） |
| 测试类型 | 功能测试 |
| 功能模块 | 系统服务与管理 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证系统日志能被正常收集，日志不为空，且最新条目与当前时间相符。

## 前置条件

1. 系统已启动。
2. 已安装日志收集服务（systemd-journald 或 rsyslog）。

## 测试步骤

1. 确定当前使用的日志收集服务：
   ```bash
   systemctl is-active systemd-journald rsyslog
   ```
   输出为 `active` 的服务即当前使用的日志收集服务。

2. 查看日志
   - systemd-journald
     ```bash
     journalctl -aeb
     ```
   - rsyslog
     ```bash
     tail /var/log/auth
     ```

     注意，日志文件路径由 `/etc/rsyslog.conf` 决定，可先用以下命令确认实际目标文件：
     ```bash
     grep -E 'auth,authpriv' /etc/rsyslog.conf
     ```

## 预期结果

1. 步骤 1：systemd-journald 与 rsyslog 中至少一个 `active`。
2. 步骤 2（按分支）：
   - systemd-journald：`journalctl -aeb` 有输出（日志不为空），最新条目时间与当前相符。
   - rsyslog：`/var/log/secure` 有输出（日志不为空），最新条目时间与当前相符。
