# TC-TR-0006-01 ｜ 系统日志正常收集

| 字段 | 值 |

| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证系统日志能被正常收集，日志不为空，且最新条目与当前时间相符。

## 前置条件（Setup）

1. 系统已启动并具备记录日志条件（journald，或 rsyslog）。

## 测试步骤（How to test）

1. 查看 journal 日志：`journalctl -aeb`。
2. 若使用 rsyslog，查看安全日志：`tail /var/log/secure`。

## 预期结果（Expected Results）

1. 步骤 1：`journalctl -aeb` 有输出（日志不为空）。
2. 最新日志条目时间与当前时间和日期相符。
