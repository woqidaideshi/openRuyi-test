# TC-TR-0008-01 ｜ 修改当前用户密码

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0008（应当能够正常修改当前用户密码） |
| 测试类型 | 功能测试 |
| 功能模块 | 系统服务与管理 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证 passwd 修改当前用户密码后新密码可登录、旧密码失效、且不能修改其他用户密码。

## 前置条件

使用正确密码登录 openruyi 账户

## 测试步骤

1. 使用 passwd 修改密码，退出码应为 0
2. 退出登录
3. 尝试旧密码登录
4. 使用新密码登录
5. 尝试修改其他用户密码

## 预期结果

1. 修改密码退出码为 0
2. 旧密码无法登录
3. 新密码可以登录
4. openruyi 无法修改其他用户密码
