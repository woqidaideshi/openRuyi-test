# TC-TR-0008-01 ｜ 修改当前用户密码

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0008（应当能够正常修改当前用户密码） |
| 测试类型 | 功能测试 |
| 功能模块 | 系统服务与管理 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证 `passwd` 能修改当前用户密码，新密码可登录、旧密码失效，且 openruyi 用户无法修改其他用户密码。

## 前置条件（Setup）

1. 使用正确密码登录 `openruyi` 账户。

## 测试步骤（How to test）

1. 修改当前用户密码：`passwd`，按提示输入新密码，记录退出码。
2. 退出登录：`exit`。
3. 尝试用旧密码登录，观察是否被拒绝。
4. 用新密码登录，观察是否成功。
5. 登录后尝试修改其他用户密码：`passwd <其他用户>`，观察是否被拒绝。

## 预期结果（Expected Results）

1. 步骤 1：`passwd` 退出码为 0。
2. 步骤 3：旧密码登录被拒绝。
3. 步骤 4：新密码登录成功。
4. 步骤 5：openruyi 无法修改其他用户密码（被拒绝，提示权限不足）。
