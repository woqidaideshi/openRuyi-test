| 自动化等级（执行方式） | 半自动 |
| 适用平台/发布件 | rva20/rva23 · 安装/镜像产物 |
| 相关软件包 | systemd |
| 实现脚本路径 | tests/functional/system/systemd/ |
| 状态 | 草稿 |

## 描述

验证 systemctl start/stop/enable/disable 对服务生命周期的管理表现正常。

## 前置条件

systemd init；选定目标服务

## 测试步骤

1. 执行 systemctl start <服务>
2. systemctl status 确认 active
3. 执行 systemctl stop 确认 inactive
4. 执行 systemctl enable
5. 执行 systemctl disable 并核对启用状态

## 预期结果

1. start/stop/enable/disable 均正常返回
2. 服务状态与命令一致
3. 退出码为 0
