## 描述

验证 reboot 重启与 shutdown 关机正常，重启后非 root 账户可登录。

## 前置条件

具备关机/重启条件，虚拟控制台可登录

## 测试步骤

1. 切换到虚拟控制台，root 登录
2. 执行 reboot
3. 等待系统重启完成
4. 使用非 root 账户登录（无则先创建）
5. 执行 shutdown 关机

## 预期结果

1. 系统正常重启并进入登录界面
2. 非 root 账户可登录
3. shutdown 后系统正常关机
