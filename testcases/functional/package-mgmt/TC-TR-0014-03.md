# TC-TR-0014-03 ｜ 异常包操作与错误码

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0014（包管理功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 软件包管理 |
| 优先级 | P0 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证异常包操作返回合理错误码，不损坏已有包、不产生半安装状态。

## 前置条件

1. 具备 root 权限（sudo）。
2. 已配置可用的 dnf 软件源。
3. 存在一个普通用户账户（如 `openruyi`），用于验证权限不足场景。

## 测试步骤

1. 采集包状态基线：
   ```bash
   CASE_TMP=/tmp/tc-pkgmgr && mkdir -p $CASE_TMP
   sudo dnf check --dependencies 2>&1 | sort > $CASE_TMP/pkgcheck.before
   sudo rpm -Va --nofiles --nodigest 2>&1 | sort > $CASE_TMP/rpmva.before
   ```
2. 安装不存在的包：
   ```bash
   sudo dnf install -y not-exist-pkg-xyz
   ```
3. 卸载未安装的包：
   ```bash
   sudo dnf remove -y not-exist-pkg-xyz
   ```
4. 以普通用户身份安装：
   ```bash
   sudo -u openruyi dnf install -y htop
   ```
5. 使用 rpm 安装**截断的真实包**：
   ```bash
   sudo dnf download --destdir $CASE_TMP htop
   head -c 3000 $CASE_TMP/htop-*.riscv64.rpm > $CASE_TMP/bad.rpm
   sudo rpm -ivh $CASE_TMP/bad.rpm
   ```
   > 不建议用 `dd if=/dev/urandom` 造“损坏包”：rpm 会把随机内容当成文件清单解析，报出 `open of <乱码> failed: No such file or directory`，语义不明。
6. 选择一个本机未装的包，以事务中止方式安装（模拟用户取消）：
   ```bash
   PKG=$(comm -13 <(rpm -qa --qf '%{name}\n' | sort -u) \
                  <(dnf repoquery --available --qf '%{name}\n' 2>/dev/null | sort -u) | head -1)
   sudo dnf --assumeno install -y "$PKG"
   rpm -q "$PKG"
   ```
   > 必须用未安装的包：若包已安装，`--assumeno` 只会输出 `Nothing to do.` 且退出码为 `0`，无法验证中止行为。
7. 重新采集包状态并与基线比对：
   ```bash
   sudo dnf check --dependencies 2>&1 | sort > $CASE_TMP/pkgcheck.after
   sudo rpm -Va --nofiles --nodigest 2>&1 | sort > $CASE_TMP/rpmva.after
   diff $CASE_TMP/pkgcheck.before $CASE_TMP/pkgcheck.after
   diff $CASE_TMP/rpmva.before $CASE_TMP/rpmva.after
   ```
8. 清理临时目录：
   ```bash
   rm -rf $CASE_TMP
   ```

## 预期结果

1. 步骤 1：两个基线文件生成成功（内容为系统当前已有的问题，可能为空）。
2. 步骤 2：退出码非 `0`，提示 `No match for argument`。
3. 步骤 3：dnf 对未安装包返回 `0`，输出 `Nothing to do.`，不误删其他包。
4. 步骤 4：退出码非 `0`，提示需要超级用户权限。
5. 步骤 5：退出码非 `0`，提示包已损坏、无法安装，不产生半安装状态。
6. 步骤 6：`--assumeno` 输出 `Operation aborted by the user.`、退出码为 `1`；`rpm -q "$PKG"` 退出码仍为 `1`，未产生半安装状态。
7. 步骤 7：两次 `diff` 均无输出（退出码 `0`），说明异常操作未新增任何包状态问题。
8. 步骤 8：清理完毕，临时目录已删除。
