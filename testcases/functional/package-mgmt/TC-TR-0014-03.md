# TC-TR-0014-03 ｜ 卸载与依赖保护

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0014（包管理功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 软件包管理 |
| 优先级 | P0 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证卸载未被依赖的软件包成功，卸载被依赖包时被拒绝并给出合理错误。

## 前置条件

1. 已安装一个测试包（示例：`htop`）。
2. 具备 root 权限（sudo）。

## 测试步骤

1. 安装测试包 `htop`（如未安装）：
   ```bash
   sudo dnf install -y htop
   ```
2. 卸载未被依赖的软件包并记录退出码：
   ```bash
   sudo dnf remove -y htop
   echo $?
   rpm -q htop
   ```
3. 卸载被其他包依赖的软件包（以 `glibc` 为例），先用 rpm 观察是否被拒绝：
   ```bash
   sudo rpm -e glibc
   echo $?
   ```
4. dnf 交叉验证同一操作（加 `--assumeno`，只求解不执行，避免真删）：
   ```bash
   sudo dnf remove --assumeno glibc
   echo $?
   ```
5. 核对依赖包未被误删：
   ```bash
   rpm -q glibc
   ```

## 预期结果

1. 步骤 2：卸载成功，退出码为 `0`；`rpm -q htop` 退出码为 `1`，提示 `package htop is not installed`。
2. 步骤 3：`rpm -e glibc` 被拒绝，退出码非 `0`，输出 `error: Failed dependencies:` 并列出依赖方。
3. 步骤 4：`dnf remove` 同样被拒绝，退出码非 `0`，输出 `Failed to resolve the transaction:`。
4. 步骤 5：`rpm -q glibc` 退出码为 `0`，`glibc` 未被误删。
