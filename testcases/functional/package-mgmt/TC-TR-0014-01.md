# TC-TR-0014-01 ｜ rpm/dnf 命令可执行

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0014（包管理功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 软件包管理 |
| 优先级 | P0 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 rpm、dnf 命令可正常执行并返回结果。

## 前置条件

1. 已安装 rpm、dnf。
2. 已配置可用的 dnf 软件源。

## 测试步骤

1. 查看 rpm 版本与已安装包列表：
   ```bash
   rpm --version
   rpm -qa | head
   echo $?
   ```
2. 查看 dnf 版本与仓库列表：
   ```bash
   dnf --version
   dnf repolist
   echo $?
   ```
3. 查询任意已安装包信息：
   ```bash
   rpm -q bash
   echo $?
   ```

## 预期结果

1. 步骤 1：`rpm --version` 正常输出版本信息，`rpm -qa` 正常输出已安装包列表，退出码为 0。
2. 步骤 2：`dnf --version` 正常输出版本信息，`dnf repolist` 正确列出已配置仓库，退出码为 0。
3. 步骤 3：`rpm -q bash` 返回包名与版本，退出码为 0。
