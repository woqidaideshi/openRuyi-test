# TC-TR-0014-01 ｜ rpm/dnf 命令可执行

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0014（包管理功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 软件包管理 |
| 优先级 | P0 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证 rpm、dnf 命令可正常执行并返回结果。

## 前置条件

1. 无。

## 测试步骤

1. 执行 `rpm -qa`。
2. 执行 `dnf list` 与 `dnf info`。

## 预期结果

1. 步骤 1：`rpm -qa` 正常输出已安装包列表，退出码为 0。
2. 步骤 2：`dnf list` / `dnf info` 正常返回结果，退出码为 0。
