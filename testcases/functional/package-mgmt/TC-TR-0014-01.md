## 描述

验证 rpm、dnf 基本命令可用；软件包能正常安装（依赖自动解析），未被依赖的包能正常卸载，被其他包依赖时卸载被拒绝。

## 前置条件

1. 已安装 rpm、dnf，具备 root 权限（sudo）。
2. 已配置可用 dnf 软件源。

## 测试步骤

1. 确认 rpm、dnf 命令可用：
   ```bash
   rpm --version
   dnf --version
   rpm -qa | head -3
   ```
2. 安装含依赖的测试包并核对依赖：
   ```bash
   sudo dnf install -y htop
   rpm -q htop
   dnf repoquery --requires htop
   rpm -q ncurses
   ```
3. 卸载未被依赖的软件包：
   ```bash
   sudo dnf remove -y htop
   rpm -q htop
   ```
4. 卸载被其他包依赖的软件包（以 `glibc` 为例）：
   ```bash
   sudo rpm -e glibc
   rpm -q glibc
   ```

## 预期结果

1. 步骤 1：`rpm --version`、`dnf --version` 正常输出版本，`rpm -qa` 正常列出已安装包，退出码为 `0`。
2. 步骤 2：安装成功，退出码为 `0`，`rpm -q htop` 返回包名与版本；`dnf repoquery --requires htop` 列出依赖项，`rpm -q ncurses` 返回版本（依赖已自动安装）。
3. 步骤 3：卸载成功，退出码为 `0`，`rpm -q htop` 退出码为 `1`（提示未安装）。
4. 步骤 4：`rpm -e glibc` 被拒绝，退出码非 `0`，输出 `error: Failed dependencies:`；`rpm -q glibc` 退出码为 `0`，未被误删。

## 实测记录（2026-11-11，riscv64 物理机）

| 步骤 | 实测结果 |
|---|---|
| 步骤 1 | `rpm --version` / `dnf --version` 正常输出，`rpm -qa` 列出 6000+ 包，`rc=0` |
| 步骤 2 | `dnf install -y htop` `rc=0`，装成 `htop-3.5.1-7.10.or.riscv64`；`repoquery --requires htop` 正常列出依赖项，`rpm -q ncurses` 返回版本 |
| 步骤 3 | `dnf remove -y htop` `rc=0`，随后 `rpm -q htop` `rc=1` |
| 步骤 4 | `rpm -e glibc` 被拒 `rc=1`，首行 `error: Failed dependencies:`（本机列出 7279 条依赖方），`rpm -q glibc` `rc=0` |

> 实测提示：`rpm -e glibc` 的依赖列表长达数千行。需要截断查看时用 `rpm -e glibc 2>&1 | head -3`，但退出码要另取一次，否则拿到的是 `head` 的 `0`。
