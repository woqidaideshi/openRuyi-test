# TC-TR-0014-02 ｜ 升级与回退

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0014（包管理功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 软件包管理 |
| 优先级 | P0 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证软件包能从源中升级到新版本，并可回退到升级前的版本。

## 前置条件

1. 已安装 rpm、dnf，具备 root 权限（sudo）。
2. 已配置可用 dnf 软件源。
3. 源中存在同时提供 2 个及以上**可安装**版本的包。

## 测试步骤

1. 在源中查找同时提供 2 个及以上可安装版本的包，选定其中一个**当前未安装**的包（记作 `<包名>`），并用 `rpm -q <包名>` 查看其安装状态。
2. 用 `dnf list --showduplicates <包名>` 查看版本清单，并用 `dnf install --assumeno <包名>-<旧版本>` 尝试安装旧版本。
3. 安装旧版本，并用 `rpm -q <包名>` 查看已安装版本。
4. 用 `dnf upgrade <包名>` 升级到新版本，并用 `rpm -q <包名>` 查看已安装版本。
5. 用 `dnf downgrade <包名>` 回退到旧版本，并用 `rpm -q <包名>` 查看已安装版本。
6. 清理：卸载该包。

## 预期结果

1. 步骤 1：输出源中具备多个可安装版本的包清单，且选定包当前未安装（`rpm -q <包名>` 提示未安装）；若无任何候选，不满足前置条件，本用例不适用。
2. 步骤 2：`--showduplicates` 至少列出 2 个版本；`--assumeno` 输出 `Operation aborted by the user.`、退出码为 1（未执行安装），且不含 `nothing provides ...`。
3. 步骤 3：安装完成，退出码为 0，`rpm -q <包名>` 显示旧版本。
4. 步骤 4：升级完成，退出码为 0，版本变为新版本。
5. 步骤 5：回退完成，退出码为 0，版本回到旧版本。
6. 步骤 6：卸载完成，`rpm -q <包名>` 提示未安装。
