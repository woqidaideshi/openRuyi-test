# TC-TR-0014-02 ｜ 升级与回退

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0014（包管理功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 软件包管理 |
| 优先级 | P0 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证软件包能从源中升级到新版本，并可回退到升级前的版本。

## 前置条件

1. 已安装 rpm、dnf，具备 root 权限（sudo）。
2. 已配置可用 dnf 软件源。
3. 源中存在同时提供 2 个及以上**可安装**版本的包。

## 测试步骤

1. 在源中搜索同时存在多个版本的包（排除 `.src` 与 `-debuginfo` 噪声）：
   ```bash
   dnf repoquery --available --qf '%{name}.%{arch} %{version}-%{release}\n' \
     | grep -vE '\.src |-debuginfo' \
     | awk '{k=$1; v=$2; if(!((k,v) in s)){s[k,v]=1; c[k]++; vs[k]=vs[k]" "v}}
              END{for(k in c) if(c[k]>1) print c[k], k, vs[k]}' \
     | sort -rn
   ```
2. 从步骤 1 的结果中选定一个包记作 `$PKG`，查看版本清单并用 `--assumeno` 尝试安装旧版本：
   ```bash
   dnf list --showduplicates "$PKG"
   sudo dnf install --assumeno "$PKG-<旧版本>"
   ```
3. 安装旧版本：
   ```bash
   sudo dnf install -y "$PKG-<旧版本>"
   rpm -q "$PKG"
   ```
4. 升级到新版本：
   ```bash
   sudo dnf upgrade -y "$PKG"
   rpm -q "$PKG"
   ```
5. 回退到旧版本：
   ```bash
   sudo dnf downgrade -y "$PKG"
   rpm -q "$PKG"
   ```
6. 清理：
   ```bash
   sudo dnf remove -y "$PKG"
   ```

## 预期结果

1. 步骤 1：列出源中多版本的包；**若无任何输出**，说明不满足前置条件，本用例不适用，需跳过。
2. 步骤 2：
   - `dnf list --showduplicates "$PKG"` 至少列出 2 个版本；
   - `sudo dnf install --assumeno "$PKG-<旧版本>"` 输出 `Operation aborted by the user.`、退出码为 `1`（未执行安装），且不含 `nothing provides ...`。
3. 步骤 3：安装成功，退出码为 `0`，`rpm -q` 显示旧版本。
4. 步骤 4：升级成功，退出码为 `0`，版本变为新版本。
5. 步骤 5：回退成功，退出码为 `0`，版本回到旧版本。
6. 步骤 6：清理完毕，`rpm -q "$PKG"` 提示未安装。
