## 描述

验证软件包安装成功且依赖被正确解析并自动安装。

## 前置条件（Setup）

1. 软件仓库可用。

## 测试步骤（How to test）

1. 安装一个含依赖的软件包：`dnf install -y <含依赖包>`。
2. 验证安装：`rpm -q <含依赖包>`。
3. 检查依赖包被自动安装：`rpm -q <依赖包>` 或 `dnf history info`。

## 预期结果（Expected Results）

1. 步骤 1：安装成功，退出码为 0。
2. 步骤 2：`rpm -q` 返回包名与版本。
3. 步骤 3：依赖包已被正确解析并自动安装。
