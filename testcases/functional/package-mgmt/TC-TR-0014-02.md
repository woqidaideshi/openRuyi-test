## 描述

验证软件包安装成功且依赖被正确解析并自动安装。

## 前置条件

1. 已安装 rpm、dnf，具备 root 权限（sudo）。
2. 已配置可用的 dnf 软件源。
3. 已选定一个含依赖的测试包（示例：`htop`，运行时依赖 `ncurses` 提供的 `libncursesw.so.6`/`libtinfo.so.6`）。

## 测试步骤

1. 安装含依赖的测试包并记录退出码：
   ```bash
   sudo dnf install -y htop
   echo $?
   ```
2. 验证测试包已安装：
   ```bash
   rpm -q htop
   ```
3. 检查依赖是否被正确解析：
   ```bash
   dnf repoquery --requires htop
   rpm -q ncurses
   ```
4. 清理（卸载测试包）：
   ```bash
   sudo dnf remove -y htop
   echo $?
   ```

## 预期结果

1. 步骤 1：安装成功，退出码为 0，依赖被自动解析并安装。
2. 步骤 2：`rpm -q htop` 返回包名与版本。
3. 步骤 3：`dnf repoquery --requires htop` 列出依赖，`rpm -q ncurses` 返回版本（依赖包已被自动安装）。
4. 步骤 4：卸载成功，退出码为 0。
