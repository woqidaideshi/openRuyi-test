# TC-TR-0014-04 ｜ 升级与回退

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0014（包管理功能） |
| 测试类型 | 功能测试 |
| 功能模块 | 软件包管理 |
| 优先级 | P0 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证软件包升级成功且可回退到上一版本。

## 前置条件

1. 已安装 rpm、dnf，具备 root 权限（sudo）。
2. 已配置可用 dnf 软件源。
3. 被测机上存在**已安装且仓库有更新版本**的包。

## 测试步骤

1. 找出可升级的包并记录升级前版本：
   ```bash
   dnf check-update
   echo $?
   dnf list --upgrades | head
   PKG=ModemManager-langpack-zh
   rpm -q "$PKG"
   ```
2. 升级该包，记录退出码与新版本：
   ```bash
   sudo dnf upgrade -y "$PKG"
   echo $?
   rpm -q "$PKG"
   ```
3. 通过事务回退恢复到升级前的版本：
   ```bash
   TID=$(dnf history list | awk 'NR==2{print $1}')
   echo "$TID"
   sudo dnf history undo "$TID" -y
   echo $?
   rpm -q "$PKG"
   ```
4. 若仓库同时提供旧版本，可另用 `dnf downgrade` 直接回退（与步骤 3 二选一）：
   ```bash
   sudo dnf downgrade -y "$PKG"
   echo $?
   rpm -q "$PKG"
   ```

## 预期结果

1. 步骤 1：`dnf check-update` 有可升级包时退出码为 `100`（无更新为 `0`），`dnf list --upgrades` 列出包名与新版本。
2. 步骤 2：升级成功，退出码为 `0`，`rpm -q` 版本号变为仓库中的新版本。
3. 步骤 3：回退成功，退出码为 `0`，`rpm -q` 版本号恢复为升级前的版本。
4. 步骤 4：`dnf downgrade` 退出码为 `0`，版本回到仓库中的旧版本；仓库只有单一版本时本步骤不适用，以步骤 3 为准。
