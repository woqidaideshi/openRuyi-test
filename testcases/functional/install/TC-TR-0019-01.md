# TC-TR-0019-01 ｜ 安装器安装失败返回错误链接

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0019（安装器安装失败后返回错误链接） |
| 测试类型 | 异常测试 |
| 功能模块 | 安装与部署 |
| 优先级 | P2 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证安装中途失败时安装器报告失败并给出可打开的日志网址，网址内容与实际失败现象一致。

## 前置条件

1. 使用 openRuyi 桌面版 ISO 启动安装器，具备图形界面。
2. 可在安装过程中移除安装目标磁盘（如 virt-manager 中 detach 磁盘，或物理机拔盘）。
3. 可访问外网。
4. 网络可达软件源。

## 测试步骤

1. 启动安装器，完成磁盘选择、分区与用户配置，开始安装。
2. 待界面进入软件包安装阶段后，移除安装目标磁盘。
3. 等待安装器报错，确认其报告失败并提供失败日志链接。
4. 打开失败日志链接，比对日志内容与本次失败现象。

## 预期结果

1. 步骤 1：安装正常开始，未出现报错弹窗或提前中止。
2. 步骤 2：移除前安装进度正常推进；移除磁盘后安装器检测到写入失败并作出反应，未在磁盘消失后静默继续。
3. 步骤 3：安装器明确报告安装失败并给出错误信息；失败提示中包含可访问的网址。
4. 步骤 4：网址可正常打开并显示本次安装对应的日志，日志内容与失败现象一致（可看到磁盘移除后的写入或读取错误）。
