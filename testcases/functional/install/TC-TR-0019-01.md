# TC-TR-0019-01 ｜ 安装失败返回错误链接

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0019（安装器安装失败后返回错误链接） |
| 测试类型 | 功能测试 |
| 功能模块 | 安装与部署 |
| 优先级 | P2 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |

## 描述

验证安装中途失败时报告安装失败并提示可打开查明的日志网址。

## 前置条件

图形界面可用

## 测试步骤

1. 安装中途（装包时）移除对应磁盘
2. 观察失败提示
3. 浏览器打开提示网址

## 预期结果

1. 报告安装失败并提示日志网址
2. 网址可打开并查明对应日志
