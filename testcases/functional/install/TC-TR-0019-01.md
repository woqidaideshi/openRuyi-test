# TC-TR-0019-01 ｜ 安装失败返回错误链接

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0019（安装器安装失败后返回错误链接） |
| 测试类型 | 功能测试 |

| 优先级 | P2 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |

## 描述

验证安装中途失败时报告安装失败并提示可打开查明的日志网址。

## 前置条件

1. 使用 openRuyi 图形版 ISO 启动安装器。
2. 可在安装过程中移除安装目标磁盘（virt-manager 中 detach，或物理机拔盘）。

## 测试步骤

1. 启动安装器，完成磁盘选择、分区与用户配置，开始安装。
2. 在安装软件包阶段，移除安装目标磁盘。
3. 等待安装器报错，记录失败提示与错误信息。
4. 记录提示中的网址，在浏览器中打开。
5. 核对网页内容与本次安装失败是否对应。

## 预期结果

1. 步骤 2：安装失败，安装器明确报告安装失败并给出错误信息。
2. 步骤 3：失败提示中包含可访问的网址。
3. 步骤 4：网址可正常打开，显示本次安装对应的日志。
4. 步骤 5：日志内容与失败现象一致，可据此定位问题。
## 执行条件说明（2026-11-10）

本用例需在 calamares 安装过程中**人为移除目标磁盘**制造失败，必须在虚拟机（virt-manager detach 磁盘）或可拔盘真机上执行，已安装系统无法回放。

补充要点：
1. 推荐在 **KVM/虚拟机** 中执行：libvirt 下可 `sudo virsh detach-disk` 或直接用 `sudo virsh blockdev` 模拟磁盘消失，比真机拔盘更可控且可重复；
2. 记录失败提示中的 URL 时，需确认该 URL 在**外部网络**可访问（若安装器使用内网地址，测试机需能解析与访问）；
3. 同时建议保留安装器本地日志作为交叉验证：
   ```bash
   ls -la /var/log/calamares/ 2>/dev/null | head
   sudo tail -50 /var/log/calamares/session.log 2>/dev/null
   ```
4. 若移除磁盘后安装器**未报错而是静默继续**，属于缺陷，需提缺陷单。
