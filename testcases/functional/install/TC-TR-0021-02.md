# TC-TR-0021-02 ｜ cloud-init 无 data iso 不启动

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0021（Cloud-init 正常使用） |
| 测试类型 | 功能测试 |
| 功能模块 | 安装与部署 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证无 data iso 时启动发布件，对应 service 不被启动。

## 前置条件（Setup）

1. 无 data iso。

## 测试步骤（How to test）

1. 不挂载 data iso 启动发布件。
2. 检查对应 service：`systemctl is-active <对应 service>`。

## 预期结果（Expected Results）

1. 步骤 2：对应 service 不被启动（`inactive`）。
