# TC-TR-018-01 ｜ 安装磁盘选择

| 字段 | 值 |
|---|---|
| 关联需求 | TR-018（安装器可以选择磁盘） |
| 需求域 | 安装与部署 |
| 优先级/门禁 | P2 |
| 自动化等级（执行方式） | 手动 |
| 适用平台/发布件 | 多磁盘 + 图形界面平台 |
| 相关软件包 | calamares |
| 实现脚本路径 | tests/functional/install/installer/ |
| 状态 | 草稿 |

## 描述

验证安装器可选择其他磁盘安装，未被选择的磁盘不受安装过程影响。

## 前置条件

存在多个磁盘

## 测试步骤

1. 安装器选择非默认磁盘
2. 完成安装
3. 检查未选磁盘

## 预期结果

1. 可选择其他磁盘安装
2. 未选磁盘不受安装过程影响
