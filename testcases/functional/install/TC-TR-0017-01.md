# TC-TR-0017-01 ｜ 安装器目标磁盘选择

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0017（安装器可以选择磁盘） |
| 测试类型 | 功能测试 |
| 功能模块 | 安装与部署 |
| 优先级 | P2 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证在安装器的安装过程中可选择非默认磁盘作为安装目标，未被选择的磁盘数据与分区表在安装前后保持一致。

## 前置条件

1. 系统配备两块及以上磁盘，且安装目标盘与验证盘（非目标盘）相互独立。
2. 验证盘上有可读写的文件系统。
3. 使用 openRuyi 桌面版 ISO 启动并进入 live 桌面。
4. 网络可达软件源。

## 测试步骤

1. 在 live 桌面记录安装前基线：磁盘列表与验证盘分区表；在验证盘写入标记文件并记录其 md5。基线数据与标记文件同存放于验证盘，不要放在 live 环境的本地目录，重启后会丢失。
2. 启动 calamares，进入磁盘选择页，查看可用磁盘列表。
3. 选择非默认磁盘作为安装目标，完成分区与用户配置后执行安装。
4. 安装完成重启进入新系统后，重新采集验证盘的分区表与标记文件 md5，并与安装前基线逐项比对。
5. 清理验证盘上的基线文件，保留标记文件。

## 预期结果

1. 步骤 1：磁盘列表与验证盘分区表输出正常；标记文件已写入验证盘，其 md5 可正常计算并记录；所有基线数据均存放于验证盘，未误存于 live 环境本地目录。
2. 步骤 2：磁盘列表完整列出所有可用磁盘，与步骤 1 记录的磁盘列表一致，未出现缺失或重复项。
3. 步骤 3：可选中非默认磁盘作为安装目标，安装正常完成，无报错。
4. 步骤 4：新安装的系统正常启动并可登录；验证盘分区表与安装前完全一致，无新增、删除或调整；标记文件 md5 与安装前相同。
5. 步骤 5：基线文件删除成功，标记文件仍存在。
