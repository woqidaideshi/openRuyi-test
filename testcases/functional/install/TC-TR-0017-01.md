# TC-TR-0017-01 ｜ 安装磁盘选择

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0017（安装器可以选择磁盘） |
| 测试类型 | 功能测试 |
| 功能模块 | 安装与部署 |
| 优先级 | P2 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证安装器可选择其他磁盘安装，未被选择的磁盘不受安装过程影响。

## 前置条件

存在多个磁盘

## 测试步骤

1. 安装器选择非默认磁盘
2. 完成安装
3. 检查未选磁盘

## 预期结果

1. 可选择其他磁盘安装
2. 未选磁盘不受安装过程影响
