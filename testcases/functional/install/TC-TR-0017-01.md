# TC-TR-0017-01 ｜ 安装磁盘选择

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0017（安装器可以选择磁盘） |
| 测试类型 | 功能测试 |
| 功能模块 | 安装与部署 |
| 优先级 | P2 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证安装器可选择其他磁盘安装，未被选择的磁盘不受安装过程影响。

## 前置条件

1. 系统配备两块及以上磁盘。
2. 其中一块（非安装目标盘）已写入标记文件并记录 md5 与分区表。
3. 使用 openRuyi 图形版 ISO 启动并进入 live 桌面。

## 测试步骤

1. 记录安装前各磁盘状态：
   ```bash
   lsblk
   ```
2. 在安装器中进入磁盘选择页，查看可用磁盘列表。
3. 选择非默认磁盘作为安装目标，完成后续配置并执行安装。
4. 安装完成后检查磁盘状态：
   ```bash
   lsblk
   ```
5. 校验未选磁盘上标记文件的 md5 与分区表未变化。

## 预期结果

1. 步骤 2：磁盘列表完整显示所有可用磁盘。
2. 步骤 3：可选中其他磁盘作为安装目标，安装正常完成。
3. 步骤 4/5：未被选择的磁盘分区表未变化，标记文件 md5 与安装前一致。

## 执行条件说明（2026-11-10）

本用例必须在 **openRuyi 图形版 ISO 的 live 桌面 + calamares 安装器** 中执行，已验证的 openRuyi riscv64 已安装系统不具备执行条件（无 ISO、无图形环境、无安装器运行实例）。

补充建议（避免误判）：
1. 选盘前先记录基线，建议包含分区表校验和：
   ```bash
   lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS
   sudo sfdisk -d /dev/<非目标盘> > /tmp/pt-before.txt
   sudo dd if=/dev/<非目标盘> bs=1M count=1 status=none | md5sum
   ```
2. 安装完成后比对：
   ```bash
   sudo sfdisk -d /dev/<非目标盘> > /tmp/pt-after.txt
   diff /tmp/pt-before.txt /tmp/pt-after.txt && echo PARTITION_TABLE_UNCHANGED
   ```
3. 非目标盘上的标记文件校验必须在**安装完成的系统内读出**（而非 live 环境），才能证明安装过程未改动该盘。
4. ⚠ 若目标盘与系统盘在同一块盘上（单盘场景），本用例不成立，需真机双盘或虚拟机双盘。
