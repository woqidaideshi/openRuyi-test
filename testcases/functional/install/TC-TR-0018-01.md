# TC-TR-0018-01 ｜ 安装用户登录

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0018（安装器创建的用户可以正常登录） |
| 测试类型 | 功能测试 |
| 功能模块 | 安装与部署 |
| 优先级 | P1 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证安装时设置的密码可登录新安装的系统。

## 前置条件

1. 使用 openRuyi 图形版 ISO 启动安装器，具备图形界面。

## 测试步骤

1. 在安装器的用户设置页面创建用户，设置用户名与密码。
2. 完成安装并重启，进入新安装的系统。
3. 使用安装时设置的用户名与密码登录。
4. 确认当前用户：
   ```bash
   whoami
   ```

## 预期结果

1. 步骤 1：用户创建成功。
2. 步骤 2：系统正常启动，进入登录界面。
3. 步骤 3：使用安装时设置的密码登录成功。
4. 步骤 4：`whoami` 输出与安装时设置的用户名一致。

## 执行条件说明（2026-11-10）

本用例需完整的“安装器建用户 → 重启 → 登录新系统”链路，无法在已安装系统上回放，需使用图形版 ISO 安装后验证。

可复用经验（已在 TC-TR-0008-01 实测）：
1. 验证密码登录时，建议用 `sshpass` + 显式密码认证选项，避免 key 优先导致“未真正验证密码”：
   ```bash
   sshpass -p '<安装时设置的密码>' ssh -n -o PreferredAuthentications=password \
     -o PubkeyAuthentication=no -o NumberOfPasswordPrompts=1 <用户名>@localhost 'whoami'
   ```
2. 若密码登录失败，先用 `sudo faillock --user <用户名> --reset` 排除锁定，再判断是否为安装器建密失败。
3. 额外的强校验：确认密码哈希算法正确（应为 yescrypt `$y$`，若为 13 字符无前缀则为 DES 弱哈希，参考 TC-TR-0008-01 已知问题）：
   ```bash
   sudo getent shadow <用户名> | cut -d: -f2 | cut -c1-4
   ```
