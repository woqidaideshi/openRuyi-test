# TC-TR-0018-01 ｜ 安装用户登录

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0018（安装器创建的用户可以正常登录） |
| 测试类型 | 功能测试 |
| 功能模块 | 安装与部署 |
| 优先级 | P1 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证安装时设置的密码可登录新安装的系统。

## 前置条件

1. 图形界面可用。

## 测试步骤

1. 安装时设置用户名与密码。
2. 安装完成并重启进入登录界面。
3. 使用安装时设置的密码登录。

## 预期结果

1. 步骤 1：用户创建成功。
2. 步骤 3：使用该密码登录成功。
