# TC-TR-0018-01 ｜ 安装器创建用户登录

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0018（安装器创建的用户可以正常登录） |
| 测试类型 | 功能测试 |
| 功能模块 | 安装与部署 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证安装时创建的用户与口令可以登录新安装的系统，且口令以安全哈希算法存储。

## 前置条件

1. 使用 openRuyi 桌面版 ISO 启动安装器，具备图形界面。
2. 网络可达软件源。

## 测试步骤

1. 在安装器的用户设置页面创建用户，设置用户名与口令，完成安装并重启。
2. 在安装的新系统的登录界面，使用安装时设置的用户名与口令登录。
3. 执行 `whoami` 和 `id` 确认当前用户身份。
4. 执行 `sudo getent shadow <用户名>` 确认口令哈希算法。

## 预期结果

1. 步骤 1：用户创建无报错，安装正常完成，重启后进入登录界面而非停留在失败状态。
2. 步骤 2：使用安装时设置的用户名与口令登录成功，正常进入桌面或会话，无认证失败提示。
3. 步骤 3：`whoami` 输出与安装时设置的用户名一致；`id` 正常显示该用户的 uid、gid 与所属组。
4. 步骤 4：口令哈希字段以 `$y$`、`$6$` 或 `$2b$` 开头，即分别使用 yescrypt、sha512、bcrypt 算法；若整个字段为 13 个字符且不含 `$`（DES），或以 `$1$` 开头（MD5），则为弱哈希，判定为缺陷。
