# TC-TR-0020-01 ｜ 安装完成后系统分区自动扩容

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0020（安装完成磁盘正常扩容） |
| 测试类型 | 功能测试 |
| 功能模块 | 安装与部署 |
| 优先级 | P2 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证安装完成后根分区自动扩展到磁盘可用空间，磁盘末尾不留大块未分配空间。

## 前置条件

1. 通过 openRuyi 安装介质完成系统安装，目标磁盘容量明显大于最小安装需求（如 32G）。
2. 网络可达软件源。

## 测试步骤

1. 选择大容量磁盘作为安装目标，完成安装并重启，登录系统。
2. 查看磁盘与根分区的容量。
3. 查看分区表与磁盘末尾的剩余未分配空间。
4. 若根分区位于 LVM 之上，查看物理卷与逻辑卷是否已扩展到所在分区的末尾。

## 预期结果

1. 步骤 1：安装完成，系统正常启动并可使用安装时创建的账户登录。
2. 步骤 2：根分区总容量接近系统磁盘的总容量，未停留在最小安装大小。
3. 步骤 3：根分区扩展到系统磁盘末尾的可用位置，其后未分配空间为 0 或仅剩对齐、GPT 备份表等 MB 级以下的保留区域。
4. 步骤 4：物理卷大小与所在分区容量一致，根逻辑卷占据卷组全部可用空间；两者均允许 MB 级差异（分区对齐、LVM 元数据占用）；未使用 LVM 时本步骤不适用，判为通过并在记录中说明。
