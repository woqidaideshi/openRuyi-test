# TC-TR-0020-01 ｜ 安装后磁盘自动扩容

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0020（安装完成磁盘正常扩容） |
| 测试类型 | 功能测试 |
| 功能模块 | 安装与部署 |
| 优先级 | P2 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证安装完成后系统磁盘自动扩容到合理大小。

## 前置条件

1. 使用 openRuyi 图形版 ISO 安装；目标磁盘容量明显大于最小安装需求（如 32G）。

## 测试步骤

1. 安装完成后重启并登录系统。
2. 检查磁盘分区容量：
   ```bash
   lsblk
   df -h /
   ```
3. 查看分区表与剩余未分配空间：
   ```bash
   sudo parted /dev/<系统盘> print
   ```

## 预期结果

1. 步骤 2：根分区可用容量与磁盘总容量相符，未停留在最小安装大小。
2. 步骤 3：分区已扩展到磁盘末尾，无未分配空间（或符合产品约定的大小）。

## 执行条件说明（2026-11-10）

本用例需在“安装时磁盘容量明显大于最小需求”的环境完整安装后验证，已安装系统无法回放（除非另做扩容演练）。

补充要点：
1. 建议在**虚拟机**中完成：先给 32G 磁盘安装，验证根分区已占满 32G；再在关机后扩容磁盘到 64G 并启动，观察是否自动 growpart + resize：
   ```bash
   lsblk
   df -h /
   sudo parted /dev/<系统盘> print free    # 应无大块 free space
   ```
2. 判断“是否自动扩容”的关键是 `parted print free` 中 **Free Space 是否为 0（或接近 0）**，只看 `df -h` 可能因文件系统已 resize 但分区未扩展而误判。
3. 若根分区使用 LVM/xfs，还需分别确认 `pvdisplay`/`lvextend` 与 `xfs_growfs` 均已执行到磁盘末尾。
