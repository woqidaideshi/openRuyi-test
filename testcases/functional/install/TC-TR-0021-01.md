# TC-TR-0021-01 ｜ cloud-init 有 data iso 启动服务

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0021（Cloud-init 正常使用） |
| 测试类型 | 功能测试 |
| 功能模块 | 安装与部署 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 是 |
| 自动化覆盖 | 否 |

## 描述

验证挂载 data iso 启动 service 发布件后对应 service 被启动并可执行相关命令。

## 前置条件

1. data iso 已准备（包含 cloud-init 配置）。

## 测试步骤

1. 挂载 data iso 到发布件。
2. 启动 service 发布件。
3. 检查对应 service：`systemctl is-active <对应 service>`，并执行相关命令。

## 预期结果

1. 步骤 3：对应 service 状态为 `active`（被启动）。
2. 相关命令执行成功。
