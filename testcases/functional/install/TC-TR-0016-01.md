# TC-TR-0016-01 ｜ calamares 安装器启动

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0016（安装器能够运行） |
| 测试类型 | 功能测试 |
| 功能模块 | 安装与部署 |
| 优先级 | P1 |
| 覆盖设备 | KVM/物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证在 live 桌面点击 calamares 图标后安装器正常弹出，界面元素与样式正常。

## 前置条件

1. 使用 openRuyi 桌面版 ISO 启动并进入 live 桌面，具备可用的图形显示输出。
2. calamares 已随镜像安装，应用菜单中存在安装入口。

## 测试步骤

1. 确认安装器已安装，执行 `rpm -q calamares`。
2. 确认存在桌面入口，执行 `ls /usr/share/applications/ | grep -i calamares`。
3. 打开应用菜单（Launcher），选择 Install System，点击图标启动安装器。
4. 观察等待期间窗口状态，记录从点击到窗口完全弹出所需时间。
5. 观察窗口布局、文字、图标与控件渲染情况。

## 预期结果

1. 步骤 1：输出版本号。
2. 步骤 2：输出中存在 `calamares.desktop`。
3. 步骤 3：菜单中存在 Install System 条目，点击后进程正常启动，无报错弹窗。
4. 步骤 4：窗口正常弹出，无卡死、无崩溃、无长时间无响应。
5. 步骤 5：界面元素完整，布局、字体、图标与控件显示正常，无乱码、花屏或控件错位。
