# TC-TR-0016-01 ｜ calamares 安装器启动

| 字段 | 值 |
|---|---|
| 关联需求 | TR-0016（安装器能够运行） |
| 测试类型 | 功能测试 |
| 功能模块 | 安装与部署 |
| 优先级 | P1 |
| 覆盖设备 | 物理机 |
| 可自动化 | 否 |
| 自动化覆盖 | 否 |

## 描述

验证点击 calamares 图标后安装器正常弹出且样式正常。

## 前置条件

1. 使用 openRuyi 图形版 ISO 启动并进入 live 桌面。
2. calamares 已安装。

## 测试步骤

1. 确认安装器已安装：
   ```bash
   rpm -q calamares
   ls /usr/share/applications/ | grep -i calamares
   ```
2. 点击桌面/菜单中的 calamares 图标（或在终端执行 `calamares`）。
3. 等待安装器窗口弹出，记录启动耗时。
4. 观察窗口布局、文字与控件渲染。

## 预期结果

1. 步骤 1：`rpm -q calamares` 正常返回版本，应用菜单中存在 calamares 条目。
2. 步骤 2/3：calamares 安装器窗口正常弹出，无卡死、无崩溃、无报错弹窗。
3. 步骤 4：界面样式正常（布局、文字、控件无错乱/缺失）。

## 实测记录与执行条件（2026-11-10）

在已验证的 openRuyi riscv64 **已安装系统**（非 live 桌面）上可确认的部分：

| 检查项 | 实测结果 |
|---|---|
| `rpm -q calamares` | `calamares-3.4.2-7.10.or.riscv64`（已安装） |
| 桌面入口 | `/usr/share/applications/` 中存在 `calamares.desktop` |
| 动态库依赖 | `ldd $(command -v calamares)` 缺失库数 = `0`（依赖完整） |
| 图形环境 | `DISPLAY` 未设置，`/tmp/.X11-unix/` 不存在，未安装 `Xvfb`/`xvfb-run`；`calamares --version` 无输出 |

**结论**：包体、桌面入口与依赖链均正常；但**安装器为 GUI 程序，无法在无显示（headless）环境下启动验证**，`calamares --version` 也需要可用的图形/平台插件才能输出。

**执行本用例所需环境**：
1. openRuyi 图形版 ISO 启动后的 live 桌面（真实显示器或 virt-manager 图形控制台）；
2. 若需在服务器上自动化验证，可先安装 `Xvfb` 后用 `xvfb-run -a calamares` 验证“能否启动不崩溃”，但**无法验证界面样式**；
3. 无 `DISPLAY` 时不要直接把“无输出”判为失败——应用户在具备图形环境时再判定。
