## 描述

验证系统启动->登录->基础命令可用，作为全部功能测试的前置门禁。

## 前置条件

安装产物/镜像/oci 就绪，可按形态启动

## 测试步骤

1. 按发布件形态启动系统
2. 等待进入登录界面
3. 使用 root 或 openruyi 登录
4. 依次执行 echo/date/uname/ls/whoami
5. 查看 journalctl 启动日志

## 预期结果

1. 系统启动完成并进入登录界面
2. 登录成功
3. 基础命令均返回预期输出且退出码为 0
4. 日志非空且最新条目时间与当前相符
